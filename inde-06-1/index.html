    • 4. 核心理论：市场结构的内生性

    inde-06-1

    总结

    1. 核心概念：使用SSNIP标准界定相关市场

    • 基本原理：SSNIP（小幅但显著且非暂时性价格上涨）测试是反垄断分析中界定市场的核心工具。其逻辑是：在一个假想的垄断下，如果对一组产品提价5%-10%是有利可图的，那么这组产品就构成一个独立的“相关市场”，因为消费者没有足够好的替代品可以转向。
    • 核心案例：中国高端白酒市场
      • 问题：茅台是否因其独特性而独立于其他高端白酒，自成一个市场？
      • 方法：通过反事实模拟进行SSNIP测试。
      • 结论：
        1. 茅台与五粮液：模拟二者合并后，双方产品价格均会显著上涨（五粮液涨23-26%，茅台涨7-15%）。这有力地证明了它们处于同一个紧密竞争的相关市场内。
        2. 茅台、五粮液与国窖1573：模拟三者合并后，国窖1573价格将出现近40-50%的巨幅上涨。这表明这三大品牌共同构成了一个高度集中的核心竞争市场。

    2. 市场界定的复杂性与多维方法

    市场界定远比理论复杂，存在多种视角和挑战：

    • 消费替代视角（需求端）的模糊性：
      • 案例：Apple Watch vs. 传统奢侈手表（如劳力士）。尽管价格差异巨大，但苹果通过与爱马仕等奢侈品牌联名，模糊了其品牌定位，使其在某种程度上与传统奢侈品产生了竞争关系，导致市场边界难以界定。
    • 生产过程视角（供给端）：
      • 方法：采用北美行业分类系统（NAICS）等标准，根据产品的生产工艺来划分市场。
      • 应用：在此体系下，Apple Watch（电子产品）和劳力士（珠宝贵金属）属于不同行业，界限清晰。但这种方法可能忽略实际的消费行为和市场竞争。
    • 其他复杂因素：
      • 地理范畴：地方市场与全国市场的界限模糊（如报业）。
      • 纵向关系：企业同时生产中间品和最终品（如华为），难以简单归类其市场位置（上游/下游）。
      • 供应链差异：同一行业内，不同环节的集中度可能差异巨大（如软饮料的制造商集中度高，而瓶装商集中度低）。

    3. 从市场界定到市场集中度衡量（HHI）

    • 重点转移：讲座从如何“定义”市场，转向如何“衡量”已定义市场内的竞争程度。
    • 主要工具：赫芬达尔-赫希曼指数（HHI）和集中度比率。
    • 方法论警示：讲者提醒，在学术研究（尤其是中文文献）中，HHI的计算方法可能存在不规范之处（如将银行分支机构视为独立公司），在严谨的学术写作中需审慎使用。
    • 教学重点：对于学生而言，本次学习的核心是掌握HHI的计算方法，而复杂且充满争议的市场定义过程则不作为考试重点。

    4. 核心理论：市场结构的内生性

    • 观点：市场结构（如企业数量）并非外部给定的，而是由市场基本条件决定的内生变量。
    • 理论模型：通过构建一个包含成本函数、等弹性需求和自由市场准入等假设的经济学模型，推导出均衡状态下的企业数量N。
    • 结论：市场中的企业数量（N）由市场总支出（E）、固定成本（F）和竞争强度（θ）共同决定。这表明市场集中度是市场内在经济力量作用的结果。

    总而言之，该讲座以SSNIP测试为切入点，通过中国高端白酒市场的实证案例，深入剖析了在反垄断实践中如何界定相关市场。随后，探讨了市场界定的多种复杂情况（如Apple Watch、地理和纵向关系），并最终引出市场集中度的衡量（HHI）以及市场结构本身是由经济基本面决定的（内生性）这一核心理论。

    经济学家通常采用SSNIP（小幅但显著且非暂时性价格上涨）标准来界定相关市场。其基本原理是：在一个假想的垄断情境下，若某一产品或服务价格小幅上涨，消费者行为（如转向替代品）不足以使垄断者亏损，则该产品或服务构成一个独立的市场。我曾撰写一篇关于中国高端白酒市场的早期论文，对其进行了深入研究。在中国，白酒市场规模巨大，消费场景多样，不仅用于饮用，也常用于烹饪。虽然普通白酒价格相对较低，流通速度快，但如茅台这类高端白酒，其价值已超越单纯的价格范畴，更承载着品牌和文化附加值。尽管茅台在高端市场中占据独特地位，但实际上也面临诸多竞争。

    为探究这一竞争格局，我们运用了结构化估计方法进行分析。研究对象包括24款高端白酒产品，涵盖多个品牌及不同产品系列，例如国窖1573的38.5和52系列、剑南春、郎酒、汾酒、不同度数和批次的茅台产品（如43度、53度）、梦之蓝、水井坊、天之蓝等。这些样本足以代表高端白酒市场的多样性。在高端白酒市场中，一种观点认为茅台是独立产品，与其他品牌不构成直接竞争，但这需要严谨的实证数据支撑。

    首先，我们进行了交叉价格弹性测试，以评估茅台价格变动对其他高端白酒品牌需求的影响。初步结果显示，茅台价格对其他品牌的需求影响并不显著，这为市场竞争格局提供了线索。其次，根据市场经验，与茅台形成最直接竞争关系的品牌是五粮液。因此，我们设计了一项反事实模拟：假设茅台与五粮液合并，对市场价格将产生何种影响。模拟结果表明，合并后，五粮液的产品价格预计将上涨23%至26%，而茅台产品价格的涨幅则在7%至15%之间。这些涨幅虽非巨幅，但已具备统计学上的显著性，有力证明茅台和五粮液同处于一个紧密竞争的相关市场内。同时，模拟也揭示，剑南春等其他高端品牌与茅台、五粮液的直接竞争强度相对较低，未完全纳入其核心相关市场的范畴。

    进一步地，我们进行了另一次反事实模拟，假设国窖1573作为另一重要高端品牌，与茅台、五粮液一同合并。结果显示，国窖1573的价格预计将大幅上涨，涨幅接近40%至50%。这进一步强化了结论，即国窖1573、茅台和五粮液这三大品牌共同构成了一个高度相关的竞争市场。这意味着，一旦这三者合并，其市场势力足以使其价格显著上涨，消费者难以转向其他非核心市场的产品。

    综上所述，在反垄断审查中，SSNIP测试是判断并购交易是否成功的关键依据。当企业申请并购时，监管机构通常会要求其评估合并对市场竞争和消费者价格可能带来的影响，以确保市场公平与消费者利益不受损害。 SSNIP（Small but Significant Non-transitory Increase in Price）测试是判断并购交易是否成功的关键依据。其核心思想是：假设合并后的企业对产品价格实行5%的小幅但持久的上涨。如果这种涨价是有利可图的，意味着现有市场中缺乏足够的替代品来阻止消费者转向，那么所界定的市场范围是恰当的，该并购可能被批准。反之，如果涨价导致大量消费者转向其他产品，使涨价无利可图，则表明当前市场界定过窄，需要将更多替代品纳入市场范围。在市场界定过程中，地理因素常使其变得复杂。例如，当核心竞争对手合并时，若价格并未显著上涨，可能意味着消费者会选择校外购买等替代方案，从而影响对市场人口范围的定义。因此，市场界定不仅难度大，且其结果常受具体论证的影响。这通常是一个自上而下的过程，其复杂性是反垄断审查中的一大挑战。

    让我们来看另一个例子：Apple Watch。大约在2015年Apple Watch刚推出时，业界曾引发广泛争议。当时，中国社会对这种新兴的电子设备态度谨慎。例如，2015年5月5日，一位细心的网友发现中国中央电视台（CCTV）的一位主持人佩戴着Apple Watch出镜。这一事件迅速发酵，引发了关于在中国当下何为奢侈品及其普及性的激烈讨论。尽管如今Apple Watch约三千元的价格已是寻常，但在当时，它被视为一种新潮的奢侈品。由此引出一个关键问题：当我们将Apple Watch视为奢侈品时，它是否与传统的奢华腕表处于同一市场？彼时，这一问题引发了巨大争议。从价格上看，Apple Watch（约三千元）与劳力士（动辄二十万至三十万元）显然不在一个量级。然而，当我们考量Apple Watch的品牌定位时，情况变得复杂。几年前，苹果公司曾推出一款搭配爱马仕表带的Apple Watch，这使得其在传统奢侈品市场中的定位更加模糊。 Apple Watch与爱马仕的联名款，其定价已与传统奢侈手表不相上下。这种定价策略引发了市场定位的争议：Apple Watch是否与传统奢侈手表处于同一市场并构成竞争？从数据分析的角度看，这需要实证支撑。如果Apple Watch通过与奢侈品牌合作，使其价格达到传统奢侈手表水平，那么它们之间实际上就存在竞争关系。这使得Apple Watch与传统手表之间的市场界定变得模糊且极具争议。

    鉴于此，除了通过市场交叉弹性、相关性或创新性来界定市场外，还有另一种方法是基于生产过程进行划分，即参考北美行业分类系统（NICS）。NICS根据经济活动类型对企业进行分类，其核心在于依据产品的生产工艺来划分市场。NICS系统包含制造、零售等大类，每个大类下又设有细致的子分类。例如，Apple Watch通常被归为“电子产品”类别，而根据NICS代码243940的描述，传统珠宝、贵金属及半贵金属等产品则属于另一行业范畴。尽管通过市场实证分析来验证两者是否存在实际影响是可行的，但其成本通常较高。

    综上所述，市场定义无论是基于消费、产品替代性，还是生产技术，都存在局限性。其中之一是市场边界的地理范畴问题。例如，在报业市场中，尽管存在地方性报纸，但读者同时也会阅读全国性报纸，这使得即便在特定地理区域内，市场界定也变得复杂，因为全国性品牌同样在此区域内竞争。另一个值得关注的问题是企业间的纵向关系。多数企业生产的是中间产品而非最终产品，上游和下游生产环节的差异，也使得市场定义更具挑战。 衡量市场集中度时，可能将处于不同生产阶段的企业归入同一行业，从而导致市场定义困难。以华为为例，它既生产手机等最终产品，也生产手机零部件等中间产品。这使得很难界定华为是最终产品生产商还是中间产品生产商，也难以区分其是上游还是下游生产环节。此外，供应链不同环节的集中度差异也是一个重要考量。例如，在软饮料行业，瓶装商的竞争较为激烈，集中度较低。然而，对于软饮料制造商而言，虽然产品种类繁多，但品牌数量有限，市场集中度较高，其中主要竞争者可能仅有两三家。

    总而言之，市场定义过程极其复杂，尤其是在进行实证研究时，存在诸多考量因素。稍后我们将探讨市场结构内生性问题。至此，关于市场定义的讨论告一段落。大家有什么问题吗？

    接下来我将展示一些衡量赫芬达尔-赫希曼指数（HHI）的案例。这些案例主要来自中文文献，国际学生无需过度关注，因为通常而言，英文文献中的相关方法论更为完善，而中文文献有时在此方面可能不够成熟。因此，再次强调，本主题的核心学习内容是掌握HHI及集中度比率的计算方法。至于市场定义，鉴于其与实证研究的紧密关联性和复杂性，不会是本次考试的考点。

    市场定义虽然与实际证据紧密相关，但由于数据获取和处理的复杂性，在考试中不要求进行定义，而是侧重于HHI的计算。接下来，我将展示一些国内顶尖期刊在HHI计算方面的实证方法。需要注意的是，中文文献中采用的某些实证方法，在特定语境下（尤其是在国内发表或内部交流时）可以接受，但其严谨性和规范性有时可能不足，在撰写英文论文时需谨慎。例如，金融学研究中常见的所谓银行市场竞争的衡量方法，即便在博士论文或教师论文中广泛使用，也并非总是最佳实践，其规范性仍有待商榷。 撰写此类内容时，可能会再次感到困扰。例如，在中国的银行业研究中，某类衡量方法（或许源于特定理论），即便广受欢迎并被一些银行采纳，其合理性仍值得商榷，尤其是在涉及国际银行时。究其原因，这种方法将银行分支机构等同于独立的公司实体进行市场分析。以厦门国际银行这类机构为例，尽管在某些语境下可被视为分支，但在衡量市场竞争时将其视为独立市场主体显然不妥。这种做法在国内银行业金融经济研究中实施起来非常困难。衡量市场竞争的方法多种多样，例如通过企业数量计算赫芬达尔-赫希曼指数（HHI）。尽管这些方法在理论或实践中可能被视为既定范式，但其运用需要严谨考量，无论是在中文还是英文语境下。

    接下来，我们将讨论市场结构的内生性问题。在此阶段，各位是否有任何疑问？若无，我们将深入探讨市场结构的内生性。我们的观点是，市场结构并非固定不变，而是由多种因素共同决定的。

    让我们看一个具体例子。首先，我们假设存在一个成本函数。平均成本（AC）可表示为边际成本（MC）加上固定成本（F）除以产量（Q），即 MC + F/Q。我们进一步假设存在一个等弹性需求，其弹性等于1。在此假设下，市场需求函数可表示为 P = Q^(-1)。等弹性曲线的特点是，曲线上任一点的价格（P）与数量（Q）的乘积始终为1。例如，点1的 P1 * Q1 = 1，点2的 P2 * Q2 = 1。这便是等弹性需求函数的核心思想。我们还假设该市场的总支出为 E。在此条件下，单一企业的产出可通过 总支出 / (企业数量 * 价格) 获得。

    最后一个假设是勒纳指数（Lerner Index）等于一个关于企业数量的特定函数形式。这里，参数 θ 代表竞争强度，是衡量竞争强度的重要指标。我们进一步假设这是一个自由市场，这与您在基础经济学课程中学到的原理非常相似，但略有不同。在自由市场条件下，市场价格始终等于平均成本（P = AC）。无论市场是同质的、差异化的，只要是自由市场，这一条件始终成立。

    利用 P = AC 这一信息，我们可以对 价格 - 成本 的表达式进行转化。通过一系列推导，我们可以消除边际成本项，最终得到 F/P 可以被平均成本（C + F/Q）所替代。而这个表达式，C + F/Q，则代表了某种竞争形式。 消除边际成本后，通过一系列推导，我们得到 F/(PQ) = N^θ。根据总支出条件 NPQ = E，可将 PQ 替换为 E/N。代入上述表达式，我们得到 F / (E/N) = N^θ，进一步简化为 N^(1+θ) = E/F。由此可解出企业数量 N = (E/F)^(1/(1+θ))。这表明，均衡状态下的企业数量 N 由总支出 E、固定成本 F 和参数 θ 共同决定。在此模型中，通过设定一系列假设，价格、产出和企业数量（即市场集中度）等关键变量均可被确定。
