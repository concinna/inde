    好的，这是一个非常经典的关于搭售（Tie-in Sales）或称捆绑销售的经济学模型。这个模型的核心在于解释，一个在“固定投入品”上拥有垄断地位的厂商，为什么有动机将其业务扩展到与之互补的“可变投入品”市场，即使后者原本是竞争性的。

    通过搭售，垄断者实际上实现了一种二级价格歧视（Second-degree Price Discrimination），即在无法直接区分不同消费者群体的情况下，通过设计产品和价格结构，让不同类型的消费者“自我选择”不同的价格-数量组合，从而攫取更多的消费者剩余。

    下面我将详细解释这个模型，并保留所有公式。

    搭售（Tie-in Sales）模型详解

    1. 模型设定

    这个模型描述了一个需要两种投入品的服务。

    • 固定投入品 (Fixed Input)：消费者无论消费多少服务，都必须先购买一个单位的该产品。例如：打印机、游戏机、咖啡机。
    • 可变投入品 (Variable Input)：每消费一单位的服务，就需要消耗一单位的该产品。例如：墨盒、游戏光盘、咖啡胶囊。

    基本假设：

    1. 市场结构：
      • 固定投入品的生产商是垄断者。
      • 可变投入品最初在一个竞争市场中生产和销售。
    2. 生产成本：为简化模型，假设两种投入品的生产成本都为零。
      • 固定投入品成本 \(CF = 0\)。
      • 可变投入品成本 \(c = 0\)。
    3. 消费者：市场上有两组消费者，但垄断者无法区分他们属于哪一组。
      • 第一组有 \(n₁\) 人。
      • 第二组有 \(n₂\) 人。
    4. 支付意愿 (Willingness to Pay - WTP)：两组消费者对服务有不同的总支付意愿函数 \(V(q)\)，其中 \(q\) 是服务的消费量（也等于可变投入品的消耗量）。
      • 第一组（低需求组）： $$ V ^ { 1 } ( q ) = A q - \frac { q ^ { 2 } } { 2 } $$
      • 第二组（高需求组）： $$ V ^ { 2 } ( q ) = \alpha A q - \frac { q ^ { 2 } } { 2 } \quad ( \text{其中 } \alpha > 1 ) $$ 这里的 \(α > 1\) 表明，对于相同的消费量 \(q\)，第二组消费者的初始边际支付意愿 (\(αA\)) 高于第一组 (\(A\))。
    5. 价格：
      • \(F\) 是固定投入品的价格（例如，打印机的价格）。
      • \(p\) 是每单位可变投入品的价格（例如，每个墨盒的价格）。

    2. 消费者决策

    一个理性的消费者会选择最优的消费量 \(q\) 来最大化其净效用（消费者剩余）。净效用等于总支付意愿减去总花费。

    消费者需要做两步决策： 1. 给定 \(F\) 和 \(p\)，决定购买多少 \(q\)。 2. 决定是否值得支付 \(F\) 来进入市场。

    对于任意一个消费者，其优化问题是： $$ \underset { q } { \operatorname* { m a x } } \ V(q) - F - pq $$

    以第一组消费者为例： $$ \underset { q } { \operatorname* { m a x } } \ A q - \frac { q ^ { 2 } } { 2 } - F - p q $$ 为了找到最优的 \(q\)，我们对 \(q\) 求一阶导数（First-Order Condition, FOC）并令其为零： $$ \frac { d } { d q } ( A q - \frac { q ^ { 2 } } { 2 } - F - p q ) = A - q - p = 0 $$ 解得第一组消费者的最优消费量（需求函数）为：\(q₁ = A - p\)。

    同理，对于第二组消费者： $$ \frac { d } { d q } ( \alpha A q - \frac { q ^ { 2 } } { 2 } - F - p q ) = \alpha A - q - p = 0 $$ 解得第二组消费者的最优消费量为：\(q₂ = αA - p\)。

    消费者只有在购买固定投入品后获得的净效用不为负时，才会决定购买。这个条件被称为参与约束（Participation Constraint）。 对于第一组，必须满足：\(V¹(q₁) - p*q₁ ≥ F\)，即： $$ \frac { ( A - p ) ^ { 2 } } { 2 } \geq F $$ 对于第二组，必须满足： $$ \frac { ( \alpha A - p ) ^ { 2 } } { 2 } \geq F $$

    所以，两组消费者的完整需求函数是： $$ q _ { 1 } = \left{ \begin{array} { l l } { A - p } & { \text{如果 } \frac { ( A - p ) ^ { 2 } } { 2 } \geq F } \ { 0 } & { \text{否则} } \end{array} \right. $$ $$ q _ { 2 } = \left{ \begin{array} { l l } { \alpha A - p } & { \text{如果 } \frac { ( \alpha A - p ) ^ { 2 } } { 2 } \geq F } \ { 0 } & { \text{否则} } \end{array} \right. $$

    3. 情景分析

    情景一：无搭售（基准情况）

    在这种情况下，垄断者只销售固定投入品。可变投入品在竞争市场中销售，根据经济学原理，其价格将等于其边际成本。 * \(p = c = 0\)

    将 \(p = 0\) 代入需求函数： * \(q₁ = A\) * \(q₂ = αA\)

    此时，两组消费者的消费者剩余分别为： * 第一组的剩余：\(V¹(A) - 0*A = A*A - A²/2 = A²/2\)。 * 第二组的剩余：\(V²(αA) - 0*αA = αA*αA - (αA)²/2 = (αA)²/2\)。

    垄断者需要设定固定投入品的价格 \(F\)。由于垄断者无法区分两组消费者，他只能设定一个统一的 \(F\)。如果他想把产品卖给所有消费者（通常这是利润最大化的选择），那么 \(F\) 的值不能超过支付意愿较低的那一组消费者（即第一组）所能获得的最大剩余。否则，第一组消费者将不会购买。

    因此，垄断者能设定的最高 \(F\) 为： $$ F = \frac { A ^ { 2 } } { 2 } $$ 在这种情况下，第一组消费者刚好愿意购买（净效用为0），而第二组消费者获得了 \((αA)²/2 - A²/2\) 的净效用。

    垄断者的总利润 \(π₀\)（基准利润）来自于销售固定投入品： $$ \pi_0 = n_1 F + n_2 F = (n_1 + n_2) F = (n_1 + n_2) \frac{A^2}{2} $$ （在你的原文中，使用了 \(Δ\) 代表 \(A\)，\(n\) 代表 \(n₁ + n₂\)，所以利润为 \(n * A²/2\)）。

    情景二：实施搭售

    现在，垄断者决定自己也生产和销售可变投入品，并要求所有购买其固定投入品的消费者也必须从他这里购买可变投入品。这使得垄断者可以同时控制 \(F\) 和 \(p\)。

    垄断者的目标是最大化其总利润 \(π\)，总利润由两部分构成： 1. 销售固定投入品的收入：\((n₁ + n₂)F\) 2. 销售可变投入品的收入：\(n₁ * q₁ * p + n₂ * q₂ * p\)（因为成本为0，所以收入即利润）

    同样，为了让两组消费者都购买产品，\(F\) 仍然受到第一组（低需求组）的参与约束的限制。但现在 \(p\) 不再是0。 $$ F = \frac { ( A - p ) ^ { 2 } } { 2 } $$

    我们将这个 \(F\) 的表达式代入总利润函数中，这样利润就只剩下 \(p\) 这一个决策变量： $$ \pi(p) = (n_1 + n_2) \left[ \frac{(A-p)^2}{2} \right] + n_1 (A-p)p + n_2 (\alpha A - p)p $$

    为了找到最优的 \(p\)，我们对 \(π(p)\) 求一阶导数并令其为零： $$ \frac{d\pi}{dp} = -(n_1+n_2)(A-p) + n_1(A-2p) + n_2(\alpha A - 2p) = 0 $$ 展开并整理： $$ -n_1 A + n_1 p - n_2 A + n_2 p + n_1 A - 2n_1 p + n_2 \alpha A - 2n_2 p = 0 $$ $$ (-n_1 - n_2) p + n_2 (\alpha - 1) A = 0 $$ 解出最优的 \(p\)： $$ p^* = \frac{n_2(\alpha - 1)A}{n_1 + n_2} $$

    分析这个最优价格 \(p*\)： * 当 \(α = 1\) 时（两组消费者没有区别），\(p* = 0\)。这意味着如果消费者需求同质，搭售没有意义，垄断者会免费提供可变投入品（因为成本为0），这与竞争市场的结果一致。 * 当 \(α > 1\) 时，\(p* > 0\)。需求差异越大（\(α\) 越大），或者高需求消费者占比越高（\(n₂\) 越大），垄断者设定的可变投入品价格 \(p\) 就越高。

    通过设定一个正的 \(p\)，垄断者实际上是在对消费量“征税”。由于高需求组（第二组）消费的 \(q\) 更多，他们支付的“税”也更多。这使得垄断者可以降低入门费 \(F\)（由 \(F = (A-p)²/2\) 可知，\(p>0\) 时 \(F\) 下降），以留住低需求客户，同时从高需求客户那里通过可变投入品赚取高额利润。

    原文中指出，实施搭售后的总利润为： $$ \pi = n \frac { A ^ { 2 } } { 2 } + n ( \frac { \alpha - 1 } { 2 } ) ^ { 2 } A ^ { 2 } $$ （注：这个简化公式通常在假设 \(n₁ = n₂\) 时得出）。 很明显，只要 \(α > 1\)，第二项就大于零，因此： $$ \pi > \pi_0 = n \frac{A^2}{2} $$

    结论：通过搭售，垄断者成功地将高需求消费者的一部分消费者剩余转化为了自己的利润，从而实现了比不搭售时更高的总利润。这是一种有效的价格歧视工具。

    例题

    假设一家公司垄断了新款“咖啡机”的销售，而“咖啡胶囊”市场是完全竞争的。两种产品的生产成本都为0。

    市场上有两类消费者，每类100人 (\(n₁ = 100\), \(n₂ = 100\))。 * 第一类（轻度用户）的总支付意愿为：\(V¹(q) = 20q - q²/2\)。 * 第二类（重度用户）的总支付意愿为：\(V²(q) = 30q - q²/2\)。

    \(F\) 是咖啡机的价格，\(p\) 是每颗咖啡胶囊的价格。

    问题： 1. 如果公司只卖咖啡机，不进入胶囊市场，它的最优定价 \(F\) 和总利润 \(π₀\) 是多少？ 2. 如果公司要求用户必须购买其生产的胶囊（搭售），它的最优胶囊价格 \(p*\)、咖啡机价格 \(F\) 和总利润 \(π\) 是多少？比较两种策略的利润。

    解答：

    首先，确定模型参数： * \(n₁ = 100\), \(n₂ = 100\) * 从 \(V¹(q)\) 可知 \(A = 20\) * 从 \(V²(q)\) 可知 \(αA = 30\)，所以 \(α = 30/20 = 1.5\)

    1. 无搭售情况

    • 胶囊市场是竞争的，成本为0，所以胶囊价格 \(p = 0\)。
    • 消费者最优消费量：
      • 第一组：\(q₁ = A - p = 20 - 0 = 20\)
      • 第二组：\(q₂ = αA - p = 30 - 0 = 30\)
    • 消费者的剩余：
      • 第一组：\(A²/2 = 20²/2 = 200\)
      • 第二组：\((αA)²/2 = 30²/2 = 450\)
    • 为了让两组都购买咖啡机，公司必须将咖啡机价格 \(F\) 定得不高于第一组的剩余。
      • 最优 \(F = 200\)
    • 计算总利润 \(π₀\)：
      • \(π₀ = (n₁ + n₂) * F = (100 + 100) * 200 = 40,000\)

    所以，在无搭售的情况下，公司会将咖啡机定价为200元，总利润为40,000元。

    2. 搭售情况

    • 公司现在同时设定咖啡机价格 \(F\) 和胶囊价格 \(p\)。
    • 首先，计算最优的胶囊价格 \(p*\)： $$ p^* = \frac{n_2(\alpha - 1)A}{n_1 + n_2} = \frac{100(1.5 - 1) \times 20}{100 + 100} = \frac{100 \times 0.5 \times 20}{200} = \frac{1000}{200} = 5 $$ 公司应该将每颗胶囊定价为5元。
    • 接下来，根据 \(p*\) 计算最优的咖啡机价格 \(F\)。\(F\) 仍然由第一组的参与约束决定： $$ F = \frac{(A-p^*)^2}{2} = \frac{(20-5)^2}{2} = \frac{15^2}{2} = \frac{225}{2} = 112.5 $$ 公司应该将咖啡机价格从200元下调至112.5元。
    • 计算两组消费者购买的胶囊数量：
      • \(q₁ = A - p* = 20 - 5 = 15\)
      • \(q₂ = αA - p* = 30 - 5 = 25\)
    • 计算搭售策略下的总利润 \(π\)：
      • 来自咖啡机的利润：\((n₁ + n₂) * F = (100 + 100) * 112.5 = 200 * 112.5 = 22,500\)
      • 来自胶囊的利润：\(n₁*q₁*p* + n₂*q₂*p* = (100 * 15 * 5) + (100 * 25 * 5) = 7,500 + 12,500 = 20,000\)
      • 总利润 \(π = 22,500 + 20,000 = 42,500\)

    比较与结论： * 无搭售利润 \(π₀ = 40,000\) * 搭售利润 \(π = 42,500\)

    通过实施搭售策略，公司的总利润从40,000元增加到42,500元。

    策略分析：公司通过降低“入门费”（咖啡机价格 \(F\) 从200降至112.5），吸引了所有消费者。然后，通过对“消耗品”（胶囊）收取高于成本的价格 (\(p=5\))，它从消费量更大的重度用户身上赚取了更多的利润。这种“低入门费+高消耗品费”的模式，本质上就是一种二级价格歧视。
