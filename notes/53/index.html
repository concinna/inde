    模型详解：转售价格维持 (Resale Price Maintenance, RPM)

    转售价格维持（RPM）是供应链中的一种纵向限制（Vertical Restraint），指供应商（制造商）对其分销商（经销商或零售商）销售其产品的价格进行限制。

    根据你提供的文本，RPM主要分为两种形式：

    1. 最高转售价格维持 (Maximum RPM)：供应商要求经销商的售价不得高于一个指定的价格上限。
    2. 最低转售价格维持 (Minimum RPM)：供应商要求经销商的售价不得低于一个指定的价格下限。

    下面我们分别详细探讨这两种形式的动机、效果和相关理论。

    1. 最高转售价格维持：解决“双重边际化”问题

    • 核心问题：双重边际化 (Double Marginalization)

      当供应链的上下游（例如，制造商和零售商）都拥有市场势力（即都是垄断者或拥有定价权）时，会产生双重边际化问题。

      • 第一重边际化：制造商作为垄断者，会在其生产成本之上加一个利润边际，制定出批发价（P_w）。
      • 第二重边际化：零售商将批发价P_w作为自己的“成本”，并在此基础上再加一重自己的利润边际，制定出最终的零售价（P_f）。

      这种“加价再加价”的行为导致最终的零售价格过高，销量过低。这不仅损害了消费者利益，也损害了制造商和零售商的整体利润。如果二者合并为一个“纵向一体化”的垄断企业，它们会只加一次价，从而制定一个更低的最终价格，获得更高的总利润。

    • 解决方案与效果

      供应商通过设定一个最高转售价格，可以有效地限制零售商的加价能力。这迫使零售商降低其利润边际，从而使最终价格更接近于纵向一体化时的最优价格。

      • 对供应商的好处：最终价格下降，产品销量上升，供应商自身的利润也随之增加。
      • 对社会福利的好处：价格下降，更多的消费者能够购买产品，因此社会福利（包括消费者剩余和生产者剩余）也得到改善。

    2. 最低转售价格维持：解决“搭便车”问题

    • 核心问题：搭便车 (Free-riding)

      这一理论由经济学家Lester Telser在1960年提出。当销售某些产品（尤其是技术复杂或需要体验的产品）需要提供昂贵的售前服务时，就会出现搭便车问题。

      • 例子：文本中提到了购买苹果电脑的例子。

        • 提供服务的高质量零售商（如Macy's或苹果体验店）：他们投资于店面装修、雇佣训练有素的销售人员，为顾客提供详细的产品讲解、操作演示和技术咨询。这些服务会增加他们的运营成本。
        • 不提供服务的折扣零售商（如邮购网站或折扣店）：他们不提供这些售前服务，运营成本很低，因此可以以更低的价格销售同样的产品。

      • 搭便车行为：消费者会去实体店详细咨询、体验产品（享受了售前服务），然后转头去价格更低的折扣店购买。折扣店“免费搭乘”了实体店提供的服务。

      • 后果：由于无法通过销售收回提供服务的成本，高质量零售商将失去提供这些宝贵服务的动力，最终可能停止服务甚至退出市场。这对供应商是不利的，因为这些服务对于推广产品、教育消费者、提升品牌形象至关重要，能够有效增加产品总需求。

    • 解决方案与效果

      制造商设定一个最低转售价格 P₁，并继续以边际成本 MC（这里简化为制造商的出厂价）向所有零售商供货。

      • 表面上的非理性：从静态角度看，设定最低价P₁（高于MC）会导致价格上升，需求量从q₀下降到q₁，制造商的利润似乎会减少。

      • 深层逻辑：制造商强制执行的零售利润空间 (P₁ - MC)，并不是白白送给零售商的。制造商期望（甚至要求）零售商利用这部分利润来进行促销活动、提供高质量的售前服务。

      • 需求曲线移动：这些由利润空间支撑的服务和促销活动，会提升产品的吸引力，从而使整个需求曲线向右移动（从 D 移动到 D'）。
      • 最终结果：尽管价格更高，但由于需求增加，最终的销售量可能反而增加到 q'，超过了没有RPM时的销量。

      因此，最低转售价格维持（Minimum RPM）的效果是具有两面性的： * 效率提升（Efficiency Increasing）：如果需求曲线的移动幅度足够大，能够抵消价格上涨带来的负面影响，那么RPM就是有效率的，对供应商和消费者都有利。 * 效率降低（Efficiency Decreasing）：如果需求曲线移动很小，那么RPM的主要效果就是抬高价格、限制竞争，从而损害效率。

    3. RPM 的反竞争效应 (Anticompetitive Effects)

    RPM也可能被用作促进或维持卡特尔（串通垄断）的工具。

    1. 促进经销商卡特尔 (Dealer Cartel)： 一群经销商可能私下达成协议，共同抬高售价以获取垄断利润。但这种卡特尔协议通常不稳定，因为每个成员都有偷偷降价来抢占市场份额的动机。如果他们能联合起来，说服（或强迫）上游供应商对所有经销商实施最低转售价格维持，那么这个卡特尔就变得非常容易维持。任何一个经销商胆敢降价，都会被供应商以违反合同为由进行惩罚（如停止供货）。这使得卡特尔协议的执行变得简单而有效。

      • 注意：这种做法不符合供应商的最佳利益（因为销量会下降），并且只有在品牌间竞争（inter-brand competition）不激烈的情况下才可能成功。

    2. 促进供应商卡特尔 (Supplier Cartel)： 类似的，供应商卡特尔也可以利用RPM来监督和维持彼此之间的价格协议。

    4. 形式化模型：百老汇剧院的例子

    这部分内容来自一篇学术论文（很可能是Christopher Leslie在2004年发表于RAND Journal of Economics的研究），它使用一个严谨的数学模型来分析消费者的选择行为，从而量化价格策略（如折扣、定价）对需求的影响。这是一个离散选择模型 (Discrete Choice Model)。

    • 基本效用函数

      消费者 i 选择观看剧目 j 获得的效用 u_ij 由以下公式表示：

      \[ u_{ij} = q_{ij} [ B(y_i) - P_j ]^\eta \]
      • u_ij: 消费者 i 从选项 j 中获得的效用。
      • q_ij: 代表消费者 i 对选项 j 的固有偏好或感知质量。
      • B(y_i): 代表消费者的“娱乐预算”或支付意愿，它是消费者收入 y_i 的函数。消费者需要决定将多少收入用于娱乐。
      • P_j: 选项 j 的价格。
      • [ B(y_i) - P_j ]: 购买后剩余的“娱乐预算”，可以理解为消费后获得的净效用。
      • η: 一个参数，反映了消费者对价格（或剩余预算）的敏感程度。

    • 预算/支付意愿函数

      \[ B(y_i) = \delta_1 y_i^{\delta_2} \quad \text{其中 } \delta_1 > 0, \delta_2 \in [0, 1] \]

      这个函数表明，一个人的娱乐预算随着收入 y_i 的增加而增加。参数 δ₂ 介于0和1之间，意味着存在边际递减效应：收入越高的人，收入的增加对娱乐预算的提升作用越小。

    • 不同选择下的具体效用

      模型针对几种不同的购票情景定义了具体的效用函数：

      1. 使用优惠券购买高质量票：消费者 i 获得一张高质量票的优惠券，价格为 P_c < P_h。 $$ u_{ic} = q_{ih} [ B(y_i) - P_c ]^\eta $$ 这里的效用是基于优惠价 P_c 计算的。

      2. 购买售票亭的票（有时间成本）： $$ u_{ib} = q_{ib} [ B(y_i) - P_b - \tau(y_i) ]^\eta $$ 这里的 P_b 是售票亭价格，τ(y_i) 代表时间成本，例如排队购票所花费的时间的价值。

      3. 时间成本函数： $$ \tau(y_i) = \tau_1 y_i + \tau_2 \quad (\tau(y_i) \geq 0) $$ 这个函数表明时间成本与收入相关，通常收入越高的人 (y_i 越大)，其时间的机会成本也越高 (τ_1 > 0)。

      4. 外部选项的效用 (不去看剧)： $$ u_{io} = \zeta_i^{-1} [ B(y_i) - P_j ]^{\eta_o} $$ 这里的 ζ_i 是一个个人特定的参数，η_o 是外部选项的敏感度参数。

    • 实证计量模型部分

      为了将理论模型应用于真实数据，研究者通常会使用Logit或类似的计量模型。

      \[ \xi_{ji} = \exp(X_t \beta) \]
      • ξ_{ji}: 代表了效用中可观测的部分（均值效用）。
      • X_t: 一系列可观测的变量，例如广告投入 (ads)、是否在颁奖季前 (dummy before Award)、一周中的具体某天 (various day of performance)、时间趋势 (time)等。
      • β: 待估计的系数，反映了这些变量对效用的影响程度。
      \[ S_{ji}(P_t, X_t, \Theta) = \int_{y \in Y, \xi \in \Xi} dF(y) dG(\xi | X\beta) \]

      这个公式是用来计算市场份额 (Market Share) S_{ji} 的。它表示，为了得到产品 j 的总市场份额，需要对所有不同类型的消费者（具有不同的收入 y 和不可观测的偏好 ξ）做出选择j的概率进行积分（加总）。Θ 代表模型中所有需要估计的参数（如 β, δ, η 等）。

    • 模型总结：这个复杂的实证模型旨在通过真实世界的票价、广告、消费者收入分布等数据，精确地估计出需求曲线以及各种因素对消费者选择的影响。有了这个模型，研究者就可以进行反事实模拟：例如，如果剧院取消所有折扣（这类似于实施一种最低价格策略），消费者的购票行为会如何改变？剧院的收入和利润会增加还是减少？社会福利会如何变化？

    例题：双重边际化与最高转售价格维持

    假设一个垄断的运动鞋制造商（M）将其产品卖给一个垄断的零售商（R）。 * 市场对这款运动鞋的反需求函数为：P = 100 - Q * 制造商的生产边际成本为：MC_M = 20 * 为简化问题，假设零售商除了支付给制造商的批发价外，没有其他成本。

    问题：

    1. 场景一（双重边际化）：计算没有RPM时，制造商制定的批发价 P_w，零售商制定的最终零售价 P，市场销量 Q，以及二者的利润 π_M, π_R 和总利润 Π_Total。
    2. 场景二（纵向一体化）：如果制造商和零售商合并为一家公司，最优的零售价、销量和总利润是多少？
    3. 场景三（最高RPM）：制造商如何通过设定最高转售价格来解决双重边际化问题，并达到纵向一体化的效果？

    解答：

    1. 场景一：双重边际化

    我们使用逆向归纳法 (Backward Induction)，先从零售商的决策开始。

    • 零售商 (R) 的决策： 零售商将批发价 P_w 视为其边际成本 MC_R = P_w。 其利润 π_R = (P - P_w) * Q = ((100 - Q) - P_w) * Q = 100Q - Q² - P_w*Q。 为了利润最大化，令边际收入等于边际成本：MR_R = MC_R。 MR_R = d(π_R)/dQ = 100 - 2Q。 所以，100 - 2Q = P_w => 2Q = 100 - P_w => Q = 50 - 0.5 * P_w。 这是零售商面对给定批发价 P_w 时的最优产量决策，也是制造商面对的需求曲线。

    • 制造商 (M) 的决策： 制造商知道零售商会如何反应，所以它将 Q = 50 - 0.5 * P_w 代入自己的利润函数。 首先，从零售商的需求反解出 P_w：P_w = 100 - 2Q。 制造商的利润 π_M = (P_w - MC_M) * Q = ( (100 - 2Q) - 20 ) * Q = (80 - 2Q) * Q = 80Q - 2Q²。 为了利润最大化，令边际收入等于边际成本：MR_M = MC_M。 MR_M = d(π_M)/dQ = 80 - 4Q。 由于制造商的生产成本是 MC_M = 20，但在这里我们已经将需求表示为 Q 的函数，所以此时制造商的“边际收入” 80 - 4Q 应该等于其“边际成本” 20 吗？不，这里的 P_w = 100 - 2Q 已经是制造商的（批发）价格，所以 (80-2Q) 是 P_w - MC_M。我们最大化 π_M 即可。 令 d(π_M)/dQ = 80 - 4Q = 0 => 4Q = 80 => Q = 20。

    • 计算最终结果：

      • 销量：Q = 20
      • 批发价：P_w = 100 - 2 * 20 = 100 - 40 = 60
      • 最终零售价：P = 100 - Q = 100 - 20 = 80
      • 制造商利润：π_M = (P_w - MC_M) * Q = (60 - 20) * 20 = 40 * 20 = 800
      • 零售商利润：π_R = (P - P_w) * Q = (80 - 60) * 20 = 20 * 20 = 400
      • 供应链总利润：Π_Total = π_M + π_R = 800 + 400 = 1200

    2. 场景二：纵向一体化

    合并后的公司（V）直接面对最终消费者，其边际成本就是制造商的生产成本 MC_V = 20。 * 利润 π_V = (P - MC_V) * Q = ((100 - Q) - 20) * Q = 80Q - Q²。 * 利润最大化，令 d(π_V)/dQ = 0：80 - 2Q = 0 => 2Q = 80 => Q_V = 40。 * 最优价格：P_V = 100 - 40 = 60。 * 最大总利润：Π_V = (60 - 20) * 40 = 40 * 40 = 1600。

    3. 场景三：使用最高RPM

    比较场景一和场景二： | | 价格 (P) | 销量 (Q) | 总利润 (Π) | | :--- | :---: | :---: | :---: | | 双重边际化 | 80 | 20 | 1200 | | 纵向一体化 | 60 | 40 | 1600 |

    双重边际化导致价格更高、销量更低、总利润更少。

    制造商可以通过设定最高转售价格 P_max = 60 来解决这个问题。

    • 当零售商被限制最高只能卖60元时，它为了最大化自己的销量和利润，只能选择将价格定在60元。
    • 此时，市场销量 Q = 100 - P = 100 - 60 = 40，这正是纵向一体化时的最优销量。
    • 现在，制造商需要设定一个批发价 P_w。制造商可以设定一个较高的批发价来攫取大部分利润，例如设定 P_w = 59.99，这样零售商仍然有微利，愿意继续销售，而制造商几乎获得了全部的渠道利润 (59.99 - 20) * 40 ≈ 1600。
    • 更常见的是，制造商会设定一个合理的 P_w，例如 P_w = 40，这样利润分配为：
      • π_M = (40 - 20) * 40 = 800
      • π_R = (60 - 40) * 40 = 800
      • 总利润 Π_Total = 800 + 800 = 1600。

    通过实施最高转售价格维持，制造商成功地将最终价格降低到60元，销量提升到40件，供应链总利润也达到了最大化的1600。这不仅增加了总利润，也让消费者受益（价格从80降到60）。
