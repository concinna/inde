    46.5 多层次序决策

    是的，不仅可以证明，而且这在产业组织理论中是一个非常经典的结论。

    如果市场中有 \(M\) 个层级 的次序竞争（Sequential Competition），第 \(i\) 个阶段有 \(n_i\) 个企业同时行动，那么最终的价格-成本差公式可以推广为：

    \[ P - c = \frac{a - c}{\prod_{i=1}^{M} (n_i + 1)} = \frac{a - c}{(n_1+1)(n_2+1)\dots(n_M+1)} \]

    这证明了每一个竞争层级都会以乘积的形式“稀释”市场溢价。下面我为你提供这个推广公式的数学证明和直观解释。

    1. 直观理解：层层过滤效应

    想象这个过程像是一个多层的滤网。 * 初始油水：\((a-c)\)。 * 最后一层（第 \(M\) 阶段）：面对前面所有人的产量，这一层的 \(n_M\) 个企业进行 Cournot 竞争。根据 n+1 规律，他们只能保留剩余价值的 \(\frac{1}{n_M+1}\)。 * 倒数第二层（第 \(M-1\) 阶段）：他们预判到下一层会把价值打折成 \(\frac{1}{n_M+1}\)。他们自己内部又有 \(n_{M-1}\) 个企业竞争，于是又打了一个 \(\frac{1}{n_{M-1}+1}\) 的折扣。 * 以此类推：每一层都把“上一层留下的有效价值”再除以 \((n_i+1)\)。

    2. 数学证明（递归归纳法）

    我们可以使用逆向归纳法（Backward Induction）来严格证明这一点。

    设定

    • 反需求函数：\(P = a - bQ\)，其中 \(Q = \sum_{i=1}^M Q_i\)（总产量是各阶段产量之和）。
    • 第 \(k\) 阶段：有 \(n_k\) 个企业，它们观测到之前阶段的总产量 \(Q_{pre} = \sum_{j=1}^{k-1} Q_j\)，并决定自己的产量 \(Q_k\)。

    递归推导

    第一步：考察最后一个阶段（第 \(M\) 阶段） 第 \(M\) 阶段的企业面对的需求是： $$ P = a - b(Q_{pre} + Q_M) $$ 令剩余截距 \(A_M = a - bQ_{pre}\)，则这就变成了一个标准的、有 \(n_M\) 个企业的 Cournot 竞争，其有效需求为 \(P = A_M - bQ_M\)。 根据标准 Cournot 结论，该阶段均衡价格 \(P\) 满足： $$ P - c = \frac{A_M - c}{n_M + 1} $$ 将 \(A_M\) 代回： $$ P - c = \frac{a - bQ_{pre} - c}{n_M + 1} = \frac{a - c}{n_M + 1} - \frac{b}{n_M + 1}Q_{pre} $$

    关键发现： 请注意上面这个方程。对于第 \(M-1\) 阶段的企业来说，这就是他们面对的“有效反需求函数”。

    \[ P(Q_{pre}) = \underbrace{\left( c + \frac{a-c}{n_M+1} \right)}_{\text{新截距 } a'} - \underbrace{\left( \frac{b}{n_M+1} \right)}_{\text{新斜率 } b'} Q_{pre} \]
    \[Q_{pre} = Q_{pre-1} + Q_{M-1}\]

    这意味着，第 \(M\) 阶段的反应，把第 \(M-1\) 阶段面临的市场结构进行了线性变换： 1. 斜率变平了：\(b' = \frac{b}{n_M+1}\)。 2. 潜在剩余缩水了：新截距与成本的差 \(a' - c = \frac{a-c}{n_M+1}\)。

    第二步：考察第 \(k\) 阶段的递归规律 假设第 \(k+1\) 阶段之后的竞争，已经将市场参数转化为： * 有效斜率 \(b_{k+1}\) * 有效剩余 \((a_{k+1} - c)\)

    那么第 \(k\) 阶段的 \(n_k\) 个企业，面对的是： $$ P_k = a_{k+1} - b_{k+1}(Q_{pre_k} + Q_k) $$ 这就是一个有 \(n_k\) 个企业的 Cournot 游戏。 均衡后，它会把参数继续传递给 \(k-1\) 阶段： 1. 斜率传递：\(b_k = \frac{b_{k+1}}{n_k + 1}\) 2. 剩余传递：\((a_k - c) = \frac{a_{k+1} - c}{n_k + 1}\)

    第三步：回到第 1 阶段 不断的递归，直到第 1 阶段（领导者层级）。 第 1 阶段面对的有效市场参数是： * 最终有效剩余：\((a_1 - c) = \frac{a - c}{(n_M+1)(n_{M-1}+1)\dots(n_2+1)}\) * 最终有效斜率：\(b_1 = \frac{b}{(n_M+1)(n_{M-1}+1)\dots(n_2+1)}\)

    第 1 阶段有 \(n_1\) 个企业进行 Cournot 竞争。 最终的市场均衡价格满足： $$ P - c = \frac{(a_1 - c)}{n_1 + 1} $$

    将上面的 \((a_1 - c)\) 表达式代入： $$ P - c = \frac{1}{n_1 + 1} \times \left[ \frac{a - c}{(n_2+1)\dots(n_M+1)} \right] $$

    整理后得证： $$ P - c = \frac{a - c}{\prod_{i=1}^{M} (n_i + 1)} $$

    3. 一个具体的例子（三层竞争）

    假设市场分三波进入： 1. 超级领导者（1家，\(n_1=1\)） 2. 次级领导者（1家，\(n_2=1\)） 3. 追随者（1家，\(n_3=1\)）

    这就是三个企业排队行动（A动完B动，B动完C动）。 根据公式： $$ P - c = \frac{a-c}{(1+1)(1+1)(1+1)} = \frac{a-c}{8} $$

    经济学解释： * 如果是 3 家同时 Cournot，分母是 \(3+1=4\)。价格较高。 * 如果是排队行动（Stackelberg），分母是 \(8\)。价格显著降低。 * 结论：在数量竞争中，行动次序越多（层级越多），竞争越激烈，产量越大，价格越接近边际成本。这是因为每一层先动者为了抢占市场，都会极进取地扩大产量，迫使后动者减产，但总产量是增加的。
