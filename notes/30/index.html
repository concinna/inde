    好的，我们来详细解释一下斯塔克尔伯格数量竞争模型（Stackelberg model of Quantity competition）。这是一个经典的寡头垄断模型，描述了市场中存在一个领导者（leader）和一个跟随者（follower）时的产量决策过程。

    模型概述

    斯塔克尔伯格模型是一种序贯博弈（Sequential Game）。与古诺模型（Cournot Model）中企业同时决策不同，斯塔克尔伯格模型的核心特征是决策有先后顺序：

    1. 领导者（Firm 1） 首先决定并公布自己的产量 q₁。
    2. 跟随者（Firm 2） 在观察到领导者的产量 q₁ 后，再决定自己的最优产量 q₂。

    由于领导者知道跟随者会如何根据自己的决策做出反应，因此领导者在做决策时，会把跟随者的反应考虑进去，从而选择一个对自己最有利的产量。

    模型的数学详解（保留所有公式）

    我们来逐步解析你提供的文本和公式。

    1. 基本设定

    • 市场逆需求函数（Inverse Demand Function）：价格 P 是市场总产量 Q 的函数。 $$ P = P(Q) = P(q_1 + q_2) $$ 其中 q₁ 是领导者（厂商1）的产量，q₂ 是跟随者（厂商2）的产量。
    • 博弈顺序：厂商1先选择 q₁，厂商2观察到 q₁ 后再选择 q₂。
    • 求解方法：我们使用向后归纳法（Backward Induction）来求解这个模型的均衡。这意味着我们先从博弈的最后一步开始分析，即先分析跟随者的决策。

    2. 第二阶段：跟随者（厂商2）的决策

    跟随者（厂商2）的目标是在已知厂商1产量 q₁ 的情况下，最大化自己的利润 π₂。此时，q₁ 对于厂商2来说是一个已知的常数。

    厂商2的利润函数为： $$ \pi_2(q_1, q_2) = P(q_1 + q_2) \cdot q_2 - c_2(q_2) $$ 其中 c₂(q₂) 是厂商2的成本函数。假设边际成本为常数 c。

    为了实现利润最大化，厂商2对 q₂ 求导，并令其等于零（一阶条件 FOC）： $$ \frac{\partial \pi_2}{\partial q_2} = \frac{\partial P}{\partial Q} \cdot q_2 + P(q_1 + q_2) - c = 0 $$ 通过求解这个方程，我们可以得到 q₂ 与 q₁ 的关系。这个关系被称为厂商2的反应函数（Reaction Function），记为 R₂(q₁)。 $$ q_2 = R_2(q_1) $$ 这个函数表示：对于领导者选择的任何产量 q₁，跟随者将会选择的最优产量是多少。

    3. 第一阶段：领导者（厂商1）的决策

    领导者（厂商1）非常聪明，它完全知道跟随者的反应函数 R₂(q₁)。因此，当厂商1选择自己的产量 q₁ 时，它已经预见到了厂商2将会生产 q₂ = R₂(q₁)。

    厂商1的目标是最大化自己的利润 π₁，它的利润函数可以写成： $$ \pi_1(q_1, R_2(q_1)) = P(q_1 + R_2(q_1)) \cdot q_1 - c_1(q_1) $$ 注意：你提供的原文中，利润公式 [ ( q _ { 1 } + R _ { 2 } ( q _ { 1 } ) ] q _ { 1 } 缺少了价格函数 P，这里已经修正。

    现在，厂商1选择 q₁ 来最大化这个利润函数。假设边际成本为常数 c。 $$ \max_{q_1} \pi_1 = P(q_1 + R_2(q_1)) \cdot q_1 - c \cdot q_1 $$ 为了求解 q₁，我们对 π₁ 关于 q₁ 求一阶导数（FOC），并令其等于零。这里需要使用链式法则和乘积法则： $$ \frac{d\pi_1}{dq_1} = \left[ \frac{dP}{dQ} \cdot \frac{d(q_1 + R_2(q_1))}{dq_1} \right] \cdot q_1 + P(q_1 + R_2(q_1)) \cdot 1 - c = 0 $$ 整理后得到： $$ P(q_1 + R_2(q_1)) + q_1 \left[ \frac{dP}{dQ} \right] \left[ 1 + \frac{dR_2(q_1)}{dq_1} \right] = c $$ 这就是你提供的FOC公式。

    4. 公式解读与核心思想

    • 策略替代品（Strategic Substitutes）: 在数量竞争中，产量通常是策略替代品。这意味着一个厂商增加产量，会促使另一个厂商减少产量。数学上表示为： $$ \frac{dR_2(q_1)}{dq_1} < 0 $$ 当领导者 q₁ 增加时，市场价格下降，留给跟随者的市场空间变小，因此跟随者会减少自己的产量 q₂。
    • 与古诺模型的对比:
      • 在古诺模型中，厂商1认为 q₂ 是固定的，即它假设 dq₂/dq₁ = 0。
      • 在斯塔克尔伯格模型中，领导者知道 q₂ 会随 q₁ 变化，即 dR₂(q₁)/dq₁ < 0。这个负值项意味着，当领导者增产 q₁ 时，它知道跟随者会减产 q₂ 来部分抵消价格下降的影响。这给了领导者更大的激励去扩张产量，因为它的一部分增产带来的价格下降压力被跟随者的减产所吸收了。
    • 先发优势（First-Mover Advantage）:
      • 因为领导者可以抢占更多的市场份额（生产比古诺均衡更多的产量），而跟随者只能在剩余的市场中做出最优反应（生产比古诺均衡更少的产量）。
      • 由于两家厂商面临相同的市场价格和成本（在简单模型中），产量更高的领导者显然会获得比跟随者更高的利润。这就是斯塔克尔伯格模型中的“先发优势”。

    线性需求下的具体求解

    现在我们应用这个理论到一个具体的线性需求函数案例中。

    • 设定:

      • 逆需求函数: P = A - BQ = A - B(q₁ + q₂)
      • 成本: c₁ = c₂ = c (常数边际成本)

    • 求解跟随者的反应函数 R₂(q₁): 厂商2最大化利润 π₂ = (A - Bq₁ - Bq₂)q₂ - cq₂。 FOC (对 q₂ 求导): A - Bq₁ - 2Bq₂ - c = 0。 解出 q₂，得到反应函数： $$ q_2 = R_2(q_1) = \frac{A - c}{2B} - \frac{q_1}{2} $$ 注意：你提供的原文公式 (A-c)/2BQ 是错误的，分母中不应该有 Q。这里已修正为正确的形式。 从这个式子可以看出 dR₂/dq₁ = -1/2 < 0，验证了产量是策略替代品。

    • 求解领导者的最优产量 q₁: 领导者将 R₂(q₁) 代入自己的利润函数中： π₁ = P(q₁ + R₂(q₁))q₁ - cq₁ π₁ = [A - B(q₁ + (\frac{A - c}{2B} - \frac{q_1}{2}))]q₁ - cq₁ 化简括号内的部分： π₁ = [A - B(\frac{q_1}{2} + \frac{A - c}{2B})]q₁ - cq₁ π₁ = [A - \frac{Bq_1}{2} - \frac{A - c}{2}]q₁ - cq₁ π₁ = [\frac{A+c}{2} - \frac{Bq_1}{2}]q₁ - cq₁ 对 q₁ 求导得到FOC： dπ₁/dq₁ = \frac{A+c}{2} - Bq₁ - c = 0 Bq₁ = \frac{A+c}{2} - c = \frac{A-c}{2} 解出领导者的最优产量： $$ q_1^* = \frac{A - c}{2B} $$

    • 求解跟随者的产量和市场结果: 将 q₁* 代入跟随者的反应函数： q₂* = (A - c)/(2B) - (1/2) * [(A - c)/(2B)] $$ q_2^ = \frac{A - c}{4B} $$ 你提供的原文中 q₁ 和 q₂ 的最终结果分母里都有 Q，这也是不正确的，这里已修正。*

    • 斯塔克尔伯格均衡结果:

      • 领导者产量: q₁* = (A - c) / (2B)
      • 跟随者产量: q₂* = (A - c) / (4B)
      • 市场总产量: Q* = q₁* + q₂* = 3(A - c) / (4B)
      • 市场价格: P* = A - B(Q*) = A - 3(A-c)/4 = (A + 3c) / 4

    关键观察 (Notice)

    1. 领导者产量与垄断产量的关系: 一个纯垄断厂商会选择产量 Q_m 来最大化 π_m = (A - BQ)Q - cQ。其FOC为 A - 2BQ - c = 0，解得垄断产量 Q_m = (A - c) / (2B)。 我们发现，斯塔克尔伯格领导者的产量 q₁* 与纯垄断厂商的产量完全相同。 区别在于：

      • 在垄断市场，总产量就是 Q_m。
      • 在斯塔克尔伯格市场，领导者生产 q₁* 后，跟随者还会进入市场并生产 q₂*。这使得市场总产量更高，价格更低。

    2. 与古诺均衡的比较: 在相同的线性需求和成本下，古诺均衡的解为：

      • q₁_cournot = q₂_cournot = (A - c) / (3B)
      • Q_cournot = 2(A - c) / (3B) 比较可知：
      • q₁* (领导者) > q₁_cournot (领导者产量更高)
      • q₂* (跟随者) < q₂_cournot (跟随者产量更低)
      • Q_stackelberg > Q_cournot (总产量更高)
      • P_stackelberg < P_cournot (价格更低)
      • 利润关系：π₁* > π_cournot > π₂* (领导者利润最高，古诺居中，跟随者最低)

    例题

    假设一个市场的逆需求函数为 P = 120 - Q，其中 Q = q₁ + q₂。市场中有两个厂商，他们的边际成本和固定成本都为零 (c = 0)。厂商1是斯塔克尔伯格领导者，厂商2是跟随者。请求解该市场的均衡产量、价格和各厂商的利润。

    解题步骤:

    1. 求解跟随者（厂商2）的反应函数

    厂商2的目标是最大化利润 π₂： π₂ = P \cdot q₂ = (120 - q₁ - q₂)q₂ = 120q₂ - q₁q₂ - q₂²

    对 q₂ 求导，令其等于零： ∂π₂/∂q₂ = 120 - q₁ - 2q₂ = 0

    解出 q₂，得到厂商2的反应函数 R₂(q₁)： 2q₂ = 120 - q₁ q₂ = 60 - q₁/2

    2. 求解领导者（厂商1）的最优产量

    厂商1知道厂商2会如何反应，所以它将 q₂ 的反应函数代入自己的利润函数 π₁： π₁ = P \cdot q₁ = (120 - q₁ - q₂)q₁ π₁ = (120 - q₁ - (60 - q₁/2))q₁ π₁ = (60 - q₁/2)q₁ = 60q₁ - (1/2)q₁²

    为了最大化 π₁，对 q₁ 求导，令其等于零： dπ₁/dq₁ = 60 - q₁ = 0

    解得领导者（厂商1）的最优产量： q₁* = 60

    3. 求解均衡结果

    • 厂商2的产量: 将 q₁* = 60 代入厂商2的反应函数： q₂* = 60 - (60/2) = 30

    • 市场总产量和价格: Q* = q₁* + q₂* = 60 + 30 = 90 P* = 120 - Q* = 120 - 90 = 30

    • 各厂商的利润: π₁* = P* \cdot q₁* = 30 \cdot 60 = 1800 π₂* = P* \cdot q₂* = 30 \cdot 30 = 900

    结论: 在斯塔克尔伯格均衡中，领导者厂商1生产60单位，跟随者厂商2生产30单位。市场价格为30。领导者利润为1800，跟随者利润为900，清晰地展示了“先发优势”。
