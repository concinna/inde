    01 中国反垄断

    总结

    该研究探讨了中国2018年将分散的反垄断执法权整合至国家市场监督管理总局（SAMR）这一重大改革对企业创新的影响。

    核心结论如下：

    1. 改革有效提升了执法力度：整合后的SAMR显著加强了反垄断执法，表现为反垄断案件数量和罚款金额的大幅增加，从而有效降低了市场集中度，加剧了市场竞争。

    2. 强化执法促进了企业创新：研究采用双重差分模型（DID）分析发现，在高市场集中度行业中，更强的反垄断压力促使企业研发支出增长了34%，发明专利申请数量增加了61%，全要素生产率（TFP）提高了0.152个百分点。

    3. 作用机制清晰：改革通过强化执法，打破了市场垄断，营造了更公平的竞争环境，这反过来激励了企业（尤其是大型企业）通过增加创新投入来维持其市场地位。

    4. 执法具有普适性和公平性：异质性分析表明，此次改革对国有企业和民营企业均产生了积极的创新促进作用，表明新机构的执法是无差别、不偏袒的。同时，改革对大型企业的影响更为显著。

    总之，该研究证实，中国将反垄断机构整合为统一、高效的监管体系，是一次成功的制度创新。它通过强化执法有效促进了市场竞争，并最终显著激发了企业创新活力，为营造公平竞争的市场环境和推动技术进步发挥了关键作用。

    近期一系列反垄断活动不仅导致中国金融科技企业面临创纪录的巨额罚款，还引发了全球对这类整合如何影响市场竞争和创新的广泛关注和质疑。关于反垄断干预后果的经济学研究中，争议一直存在。一方面，有研究表明反垄断执法可以促进创新（Aghion et al., 2023; Buccirosi et al., 2013; Kwon & Marco, 2021）；另一方面，也有观点认为它可能无意中抑制了企业的创新活力（Manne & Wright, 2010），从而引发了对这些政策有效性重新评估的呼吁（Crandall & Winston, 2003）。本文旨在回应这一争论，通过考察中国近期反垄断框架改革，尤其是在全球反垄断实践日益严格的背景下，评估其对企业创新的影响。

    中国近期反垄断改革正是政府机构整合这一全球趋势的体现。此前，中国的《反垄断法》（AML）执法权分散在商务部（MOFCOM）、国家发展和改革委员会（NDRC）以及国家工商行政管理总局（SAIC）三个政府机构。然而，这种分散的执法模式因效率低下、激励冲突、管辖权重叠，以及人员配备不足等问题而备受诟病（Fox & Trebilcock, 2013; Zhang, 2021）。为应对这些问题，2018年《反垄断法》修订并设立了国家市场监督管理总局（SAMR），标志着中国反垄断框架的重大改革。新成立的SAMR通过显著增加反垄断案件数量（详见图1），对市场产生了深远影响。因此，本文旨在评估此次整合的深远意义，特别是其如何影响企业在反垄断法执行方面的反应。

    本文利用来自各行业上市公司的面板数据，采用双重差分（DID）模型，考察了高集中度行业企业在研发投入、专利申请数量和全要素生产率（TFP）提升方面的反应。研究结果显示，反垄断执法力度的增强促使企业研发支出增长34%，发明专利申请数量增加61%，全要素生产率提高0.152个百分点。此外，机制分析表明，反垄断机构的整合导致反垄断案件数量和罚款金额的增加，从而有效增强了竞争并刺激了大型企业的创新。

    此外，学界长期以来一直争论中国《反垄断法》能否在不偏袒国有企业（SOEs）的情况下得到全面实施（Kovacic, 2017）。本文的异质性检验表明，新整合的反垄断机构对国有企业和民营企业产生了相似的影响。本研究通过对中国《反垄断法》重大修订及后续反垄断机构整合后执法力度强化的全面实证分析，对反垄断监管文献做出了重要贡献。尤其值得注意的是，学界普遍关注为《反垄断法》的全面实施提供经验证据，这旨在扩大中国竞争性次级经济的规模和范围（Kovacic, 2017）。据我们所知，本研究首次评估了此类机构整合对企业创新的影响。尽管此前已有研究探讨《反垄断法》本身的影响，但鲜有涉及监管机构整合的更广泛含义。本研究旨在阐明这些整合究竟代表了真正的制度创新，还是仅仅是多个机构独立职能的削弱，这是学界一直以来热切期待探讨的议题（Ottow, 2014）。

    本文结构如下：第二节简要介绍中国《反垄断法》的背景；第三节描述数据；第四节讨论实证模型并展示结果；第五节进行机制检验；第六节提供异质性分析；第七节总结全文。

    2. 中国《反垄断法》

    中国《反垄断法》于2007年由全国人民代表大会颁布，并于2008年8月1日生效，是中华人民共和国竞争法的基石。该法旨在制止和规制垄断行为，维护市场公平竞争，保护消费者利益，并促进社会主义市场经济的健康发展。

    3. 初始执法框架

    最初，《反垄断法》的执法权由商务部（MOFCOM）、国家发展和改革委员会（NDRC）和国家工商行政管理总局（SAIC）三个政府机构分管。每个机构负责反垄断执法中的不同方面。具体而言，国家工商行政管理总局负责处理垄断协议、滥用市场支配地位（价格相关问题除外）和行政权力滥用；国家发展和改革委员会侧重于价格相关的垄断行为，包括价格卡特尔和滥用支配地位；商务部则负责经营者集中审查（Ma, 2020）。

    然而，这种三方执法结构因效率低下、激励冲突、管辖权重叠以及人员配备不足等问题而广受诟病（Zhang, 2021）。此外，国家发展和改革委员会、国家工商行政管理总局、商务部与行业特定监管机构之间的职责划分仍不明确，尤其是在国有企业主导的行业。这些企业常受益于行业特定法规，从而使直接的反垄断执法复杂化（Fox & Trebilcock, 2013）。批评者认为，这些问题阻碍了中国反垄断法的发展，多个机构对其权力进行宽泛解释，导致执法不清晰且相互重叠（Hao, 2013）。 这表明，反垄断法在早期实施阶段并非政府的优先事项，或至少未能充分克服机构间对统一执法权的阻力（Zheng, 2023）。

    为应对这些挑战，中国国务院于2018年3月启动了一项重大改革，该改革经第十三届全国人民代表大会批准并于同年3月实施。此次改革促成了国家市场监督管理总局（SAMR）的成立，整合了商务部（MOFCOM）、国家发展和改革委员会（NDRC）以及国家工商行政管理总局（SAIC）的反垄断职能，有效解决了此前存在的管辖权争议和效率低下问题，从而开创了中国反垄断执法的新纪元（Ma, 2020）。随之，中国的反垄断执法经历了关键性转变，有效解决了此前三个反垄断机构间长期存在的管辖权争议。国家市场监督管理总局2019年的报告显示，与2018年相比，执法活动大幅增加，立案数量增长19.4%，罚没款总额增长11.9%。国家市场监督管理总局表示，这些数据反映出反垄断执法已成为常态化实践，标志着其在规范市场竞争方面建立了更加系统化和常态化的机制。

    图1直观呈现了中国在2018年关键性改革前后反垄断格局的分析。图1(a)显示，改革后反垄断案件数量大幅激增，凸显了对反垄断执法的承诺显著增强。图1(b)则考察了企业，特别是高赫芬达尔-赫希曼指数（HHI）和市场份额显著的行业中企业的创新响应。数据显示，这些企业在2018年后发明专利申请量显著上升，表明在严格的监管环境下，企业对创新的关注度有所提升。两幅图在改革后呈现出的分化趋势，强调了反垄断活动加强与企业创新增加之间的关联，这充分说明了此次改革对中国反垄断体系和企业战略产生的深远影响。这种强化的执法活动还包括对主要金融科技公司处以历史性高额罚款。其中一个显著案例是对阿里巴巴集团处以创纪录的28亿美元反垄断罚款，这一事件引起了全球广泛关注。国家市场监督管理总局监管下反垄断行动的激增，体现了其对市场监管的强劲姿态，也反映出中国在执行反垄断法方面的承诺发生了显著转变。 为评估统一反垄断监管框架对企业创新反应的影响，本研究聚焦于竞争政策和创新文献中广泛采用的几个关键指标：研发投入、专利申请和全要素生产率（TFP）。其中，专利申请，尤其是发明专利，被用作衡量创新努力的主要指标，这与Aghion et al. (2023)和Mann (2018)等现有文献中的普遍做法一致。在中国由国家知识产权局主管的专利体系中，主要包括发明、实用新型和外观设计三类专利。其中，“发明专利”是指对产品、方法或其改进所提出的新的技术方案；“实用新型专利”（更易获批）是指对产品的形状、构造或其结合所提出的适于实用的新的技术方案；“外观设计专利”则侧重于产品富有美感并适于工业应用的新设计。虽然现有文献（如Mann, 2018; Aghion et al., 2023）主要以发明专利作为创新指标，但本研究的主要模型也同时考察了实用新型和外观设计专利。

    全要素生产率（TFP）的计算方法是基于Levihnshn和Petrin（2003）提出的模型，并经Chen et al.（2023）改进，采用柯布-道格拉斯生产函数。在此函数中，企业的总营业收入作为产出代理，固定资产净值作为资本投入，员工数量作为劳动投入，营业成本作为中间投入。值得一提的是，虽然研发投入和专利申请是常用的创新衡量指标，但本研究将TFP作为关键指标，是参考了Buccinosi et al. (2013)、Xiao et al. (2023)和Chen et al. (2023)等近期研究的成果。主要变量的统计摘要见表1。

    为量化中国反垄断执法的强度，本研究采纳了年度反垄断立案数量数据。该数据来源于国家市场监督管理总局（SAMR）官方网站，旨在通过追踪反垄断案件的年度波动，捕捉机构改革后执法环境的演变。此外，为深化分析，我们还整合了从CSMAR数据库获取的企业反垄断违规罚款数据，该数据已汇总至城市层面。图2展示了执法强度的这些变化，具体呈现了反垄断机构合并前后，城市层面企业年度平均罚款的变化。该图清晰地揭示了合并前后执法力度的趋势，表明各城市反垄断执法行动显著升级，有效描绘了改革后监管环境的强化。

    1. 实证策略 4.1. 双重差分（DID）模型

    本研究采用标准的双重差分（DID）模型来评估国家市场监督管理总局（SAMR）成立的影响。受Segal和Whinston（2007）关于健全反垄断政策激励企业创新的观点启发，我们将在中国反垄断机构整合的背景下探讨这一概念。此前，反垄断执法由三个机构分管，这种结构因效率低下和威慑性制裁而受到批评（Ma, 2020）。因此，我们的假设是，SAMR统一且更高效的结构能够刺激市场竞争，进而促进企业的创新活动。模型设定如下：

    \[ y _ { i t } = \alpha + \beta t r e a t _ { i } \times p o s t _ { i } + X W + \sigma _ { i } + \tau _ { i } + \epsilon _ { i t } (1)\]

    其中，\( y _ { i t } \) 代表企业 \( i \) 在时间 \( t \) 的研发投入对数、专利申请对数和全要素生产率（TFP）。变量 \( Post \) 是一个二元指示符，2018年及以后设为1。根据《横向兼并指南》（2010），我们的处理组包括：不仅HHI高于2500的行业中的企业，而且这些企业在该行业中市场份额排名前三分之一。相反，HHI低于1500的行业中的企业被归类为控制组。这种分类在理论和实证上均以HHI测量的应用为基础，反映了反垄断实践中的常见做法。

    这一结果符合我们的预期，即更高效的反垄断环境主要激励竞争性创新，而非实用新型或外观设计方面的努力。此外，此次整合还使企业TFP提高了0.152。 借鉴Chen, Herrera, and Lugauer (2022)的研究方法，我们考察了在国家市场监督管理总局（SAMR）成立之前，具有高垄断权的企业在创新投入和产出方面是否与其他企业呈现相似的趋势。为验证此点，我们构建了以下模型：

    \[ y _ { i t } = \alpha + \sum _ { j = - 4 , - 3 , - 2 , 0 , 1 , 2 , 3 } ^ { 2 } \beta _ { j } D _ { j } + X W + \sigma _ { i t } + \tau _ { t } + \epsilon _ { i t } (2)\]

    其中，\(D_j\) 代表一系列虚拟变量，\(j\) 的取值为 \(-4, -3, -2, 0, 1, 2, 3\)，并省略了 \(j = -1\) 的虚拟变量，将2017年设为基准年。每个 \(D_j\) 定义为 \(treat \times post_j\)，其中 \(post_j\) 在 \(2018 + j\) 年之前为0，之后为1。该模型通过比较回归结果中 \(D\) 系列变量的系数，以评估SAMR成立前后处理组和对照组之间创新投入和产出的显著差异。图3展示了估计系数 \(\hat{\beta}_j\) 及其对应的95%置信区间，支持了双重差分（DID）模型的平行趋势假设。

    为进一步增强研究的实证严谨性，图4详细呈现了安慰剂检验的结果。在该检验中，处理组的划分和政策实施后的时期均被随机分配，并重复此过程500次。这项安慰剂检验是一项重要的稳健性检验，旨在排除未观测变量可能对结果产生影响的顾虑。综合来看，平行趋势分析和安慰剂检验显著增强了我们DID估计结果的可靠性。

    4.2 稳健性检验

    为确保研究结论的稳健性，我们进行了一系列检验，包括调整处理组和对照组的划分方式、采用不同的DID方法、调整样本以控制中美贸易战的影响，并考虑了COVID-19疫情的潜在影响。

    首先，我们采用了两种不同的处理组分类方法进行了稳健性检验。第一次检验通过扩大对照组来增强可比性：我们保留了原始处理组，即市场份额在前三分之一且所在行业赫芬达尔指数（HHI）高于2500的公司，同时将对照组扩大至HHI低于2500的行业中的企业。其次，我们借鉴了Xiao et al. (2023)的方法，使用企业的勒纳指数（Lerner index）将每个行业内勒纳指数排名前三分之一的企业划分为处理组，后三分之一划分为对照组。这种方法提供了更精细的比较，并解决了初始对照组选择可能带来的潜在偏差。表3详细列出了这些稳健性检验的结果，进一步印证了基准模型的结论。其中，第(1)至(3)列使用了扩大对照组的样本，而第(4)至(6)列则采用了基于企业勒纳指数的分类方法。这两组结果均再次证实，反垄断机构的整合促使企业增加了研发投入、申请了更多发明专利，并提升了全要素生产率（TFP），为我们的初步观察提供了额外的实证支持。这些结果也与Jiang and Bu (2023)在反垄断法（AML）初期实施时观察到的类似效应相符。

    6.2. 企业规模。我们将研究拓展至反垄断整合对不同规模企业的影响。分析中，企业根据其规模是否高于或低于中位数进行分类。表11的结果显示，此次整合对大型企业的影响更为显著，这些企业在其各自行业中面临的竞争加剧。大型和小型企业的全要素生产率（TFP）均有所提升，但小型企业可能在研发方面投入更多，而大型企业则表现出更高的发明专利申请率。这种差异化效应突显了企业规模如何影响其应对监管环境变化的能力。研究结果表明，大型企业可能因其更丰富的资源和完善的基础设施，在应对新的竞争压力和利用更严格反垄断执法所带来的创新机遇方面更具优势。相比之下，小型企业虽然也受益于市场集中度的降低，但更倾向于通过加大研发投入来增强在更具活力市场中的竞争优势。这些洞察有助于深化理解反垄断监管整合如何根据企业规模产生不同的影响，对政策制定者具有重要启示，即如何量身定制反垄断执法，以促进整个商业领域的竞争公平和创新活力。

    1. 结论。本文对中国近期反垄断执法机构整合的后果进行了严谨考察，为理解其对市场竞争和企业创新的影响提供了细致入微的视角。我们运用广泛的数据集和稳健的双重差分（DID）方法，对中国反垄断法（AML）框架下的这一重大改革进行了全面评估。尽管现有研究（如Jiang和Bu，2023）表明《反垄断法》的引入激活了中国市场经济，提升了竞争水平并刺激了企业创新，但学术界和监管界仍持续关注《反垄断法》的全面实施情况（Rovacic，2017），并对其缺乏统一的反垄断机构提出批评（Zhang，2021）。因此，本研究对中国最近将反垄断执法整合至国家市场监督管理总局（SAMR）的举措提供了及时且相关的分析。我们的研究结果表明，整合至国家市场监督管理总局有效简化并强化了反垄断执法。反垄断案件数量和处罚力度的显著增加有力地证明了这一点。此次强化执法的一个关键成果是行业集中度的显著降低以及随之而来的市场竞争加剧。此外，我们对机制的探究揭示，整合带来的执法强度提升创造了一个更具竞争力的市场环境。这一转变反过来又促进了研发投入和发明专利申请的显著增长，并带来了全要素生产率（TFP）的显著提高。这些发现强调了反垄断执法在推动行业创新和增强竞争活力方面的关键作用。此外，我们对异质性的考察表明，此次改革普遍促进了各类企业的创新，包括国有企业和民营企业。这一观察对于研究《反垄断法》条款是否得到全面执行、是否存在偏袒国有企业而损害竞争性次级经济体（Kovacic，2017）的学者而言至关重要。总之，本研究首次实证分析了中国反垄断执法机构整合的影响，为现有文献做出了重要贡献。研究得出的见解对于政策制定者和监管机构尤其宝贵。它们表明，此类整合若能有效实施，可作为强有力的催化剂，激活市场竞争并刺激企业创新。因此，本文不仅丰富了学术讨论，也为未来反垄断政策的方向提供了实践启示，强调了其在塑造竞争性市场结构和促进技术进步中的关键作用。
