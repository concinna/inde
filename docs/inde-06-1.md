经济学家通常采用SSNIP（小幅但显著且非暂时性价格上涨）标准来界定相关市场。其基本原理是：在一个假想的垄断情境下，若某一产品或服务价格小幅上涨，消费者行为（如转向替代品）不足以使垄断者亏损，则该产品或服务构成一个独立的市场。我曾撰写一篇关于中国高端白酒市场的早期论文，对其进行了深入研究。在中国，白酒市场规模巨大，消费场景多样，不仅用于饮用，也常用于烹饪。虽然普通白酒价格相对较低，流通速度快，但如茅台这类高端白酒，其价值已超越单纯的价格范畴，更承载着品牌和文化附加值。尽管茅台在高端市场中占据独特地位，但实际上也面临诸多竞争。

为探究这一竞争格局，我们运用了结构化估计方法进行分析。研究对象包括24款高端白酒产品，涵盖多个品牌及不同产品系列，例如国窖1573的38.5和52系列、剑南春、郎酒、汾酒、不同度数和批次的茅台产品（如43度、53度）、梦之蓝、水井坊、天之蓝等。这些样本足以代表高端白酒市场的多样性。在高端白酒市场中，一种观点认为茅台是独立产品，与其他品牌不构成直接竞争，但这需要严谨的实证数据支撑。

进一步地，我们进行了另一次反事实模拟，假设国窖1573作为另一重要高端品牌，与茅台、五粮液一同合并。结果显示，国窖1573的价格预计将大幅上涨，涨幅接近40%至50%。这进一步强化了结论，即国窖1573、茅台和五粮液这三大品牌共同构成了一个高度相关的竞争市场。这意味着，一旦这三者合并，其市场势力足以使其价格显著上涨，消费者难以转向其他非核心市场的产品。

综上所述，在反垄断审查中，SSNIP测试是判断并购交易是否成功的关键依据。当企业申请并购时，监管机构通常会要求其评估合并对市场竞争和消费者价格可能带来的影响，以确保市场公平与消费者利益不受损害。
SSNIP（Small but Significant Non-transitory Increase in Price）测试是判断并购交易是否成功的关键依据。其核心思想是：假设合并后的企业对产品价格实行5%的小幅但持久的上涨。如果这种涨价是有利可图的，意味着现有市场中缺乏足够的替代品来阻止消费者转向，那么所界定的市场范围是恰当的，该并购可能被批准。反之，如果涨价导致大量消费者转向其他产品，使涨价无利可图，则表明当前市场界定过窄，需要将更多替代品纳入市场范围。在市场界定过程中，地理因素常使其变得复杂。例如，当核心竞争对手合并时，若价格并未显著上涨，可能意味着消费者会选择校外购买等替代方案，从而影响对市场人口范围的定义。因此，市场界定不仅难度大，且其结果常受具体论证的影响。这通常是一个自上而下的过程，其复杂性是反垄断审查中的一大挑战。

综上所述，市场定义无论是基于消费、产品替代性，还是生产技术，都存在局限性。其中之一是市场边界的地理范畴问题。例如，在报业市场中，尽管存在地方性报纸，但读者同时也会阅读全国性报纸，这使得即便在特定地理区域内，市场界定也变得复杂，因为全国性品牌同样在此区域内竞争。另一个值得关注的问题是企业间的纵向关系。多数企业生产的是中间产品而非最终产品，上游和下游生产环节的差异，也使得市场定义更具挑战。
衡量市场集中度时，可能将处于不同生产阶段的企业归入同一行业，从而导致市场定义困难。以华为为例，它既生产手机等最终产品，也生产手机零部件等中间产品。这使得很难界定华为是最终产品生产商还是中间产品生产商，也难以区分其是上游还是下游生产环节。此外，供应链不同环节的集中度差异也是一个重要考量。例如，在软饮料行业，瓶装商的竞争较为激烈，集中度较低。然而，对于软饮料制造商而言，虽然产品种类繁多，但品牌数量有限，市场集中度较高，其中主要竞争者可能仅有两三家。

接下来，我们将讨论市场结构的内生性问题。在此阶段，各位是否有任何疑问？若无，我们将深入探讨市场结构的内生性。我们的观点是，市场结构并非固定不变，而是由多种因素共同决定的。

让我们看一个具体例子。首先，我们假设存在一个成本函数。平均成本（AC）可表示为边际成本（MC）加上固定成本（F）除以产量（Q），即 `MC + F/Q`。我们进一步假设存在一个等弹性需求，其弹性等于1。在此假设下，市场需求函数可表示为 `P = Q^(-1)`。等弹性曲线的特点是，曲线上任一点的价格（`P`）与数量（`Q`）的乘积始终为1。例如，点1的 `P1 * Q1 = 1`，点2的 `P2 * Q2 = 1`。这便是等弹性需求函数的核心思想。我们还假设该市场的总支出为 `E`。在此条件下，单一企业的产出可通过 `总支出 / (企业数量 * 价格)` 获得。

最后一个假设是勒纳指数（Lerner Index）等于一个关于企业数量的特定函数形式。这里，参数 `θ` 代表竞争强度，是衡量竞争强度的重要指标。我们进一步假设这是一个自由市场，这与您在基础经济学课程中学到的原理非常相似，但略有不同。在自由市场条件下，市场价格始终等于平均成本（`P = AC`）。无论市场是同质的、差异化的，只要是自由市场，这一条件始终成立。

利用 `P = AC` 这一信息，我们可以对 `价格 - 成本` 的表达式进行转化。通过一系列推导，我们可以消除边际成本项，最终得到 `F/P` 可以被平均成本（`C + F/Q`）所替代。而这个表达式，`C + F/Q`，则代表了某种竞争形式。
消除边际成本后，通过一系列推导，我们得到 `F/(PQ) = N^θ`。根据总支出条件 `NPQ = E`，可将 `PQ` 替换为 `E/N`。代入上述表达式，我们得到 `F / (E/N) = N^θ`，进一步简化为 `N^(1+θ) = E/F`。由此可解出企业数量 `N = (E/F)^(1/(1+θ))`。这表明，均衡状态下的企业数量 `N` 由总支出 `E`、固定成本 `F` 和参数 `θ` 共同决定。在此模型中，通过设定一系列假设，价格、产出和企业数量（即市场集中度）等关键变量均可被确定。
