### **模型详解**

这个模型分析了一家垄断企业如何通过不同的定价策略来最大化其利润。它比较了两种情况：
1.  **标准垄断定价（或第三方价格歧视）**：对不同市场（例如，年轻消费者和年老消费者）收取不同的单价。
2.  **二部定价**：收取一个固定的准入费（会员费），然后再对每单位产品或服务收取一个使用费。

#### **第一部分：基准情况 - 标准垄断定价 (Standard Monopoly Pricing)**

在这个模型中，我们假设有两个不同的消费者群体：年轻人（young, 下标y）和老年人（old, 下标o）。他们的需求曲线是线性的，并且各不相同。

*   **需求曲线 (Demand Curve):**
    *   年轻人的需求曲线: $P = V_y - Q_y$
    *   老年人的需求曲线: $P = V_o - Q_o$
    *   **解释**:
        *   $P$ 是价格。
        *   $Q$ 是数量。
        *   $V_y$ 和 $V_o$ 分别代表年轻人和老年人愿意支付的最高价格（即需求曲线在价格轴上的截距）。通常我们假设老年人有更强的支付意愿或需求，即 $V_o > V_y$。

*   **边际收益曲线 (Marginal Revenue Curve):**
    对于线性需求曲线 $P = a - bQ$，其边际收益曲线为 $MR = a - 2bQ$。在本模型中，$b=1$。
    *   年轻人的边际收益: $MR_y = V_y - 2Q_y$
    *   老年人的边际收益: $MR_o = V_o - 2Q_o$

*   **利润最大化 (Profit Maximization):**
    垄断厂商实现利润最大化的条件是**边际收益 (MR) 等于边际成本 (MC)**。我们假设边际成本 $c$ 是一个常数。
    *   **对年轻人市场**: $MR_y = c$
        $V_y - 2Q_y = c$
        解出最优数量: $Q_y = (V_y - c) / 2$
    *   **对老年人市场**: $MR_o = c$
        $V_o - 2Q_o = c$
        解出最优数量: $Q_o = (V_o - c) / 2$

*   **最优价格 (Optimal Price):**
    将最优数量 $Q$ 代入各自的需求曲线，得到最优价格 $P$。
    *   年轻人的价格: $P_y = V_y - Q_y = V_y - (V_y - c) / 2 = (V_y + c) / 2$
    *   老年人的价格: $P_o = V_o - Q_o = V_o - (V_o - c) / 2 = (V_o + c) / 2$

*   **利润 (Profit):**
    来自每个市场的利润等于 (价格 - 边际成本) × 数量。
    *   来自年轻人的利润: $Profit_y = (P_y - c) * Q_y = ((V_y + c) / 2 - c) * ((V_y - c) / 2) = (V_y - c)^2 / 4$
    *   来自老年人的利润: $Profit_o = (P_o - c) * Q_o = ((V_o + c) / 2 - c) * ((V_o - c) / 2) = (V_o - c)^2 / 4$
    *   总利润为 $Profit_total = Profit_y + Profit_o - F$，其中 $F$ 是固定成本。

*   **消费者剩余 (Consumer Surplus):**
    消费者剩余是消费者愿意支付的总额与实际支付的总额之间的差额。对于线性需求曲线，它是一个三角形的面积。
    *   年轻人的消费者剩余: $CS_y = (1/2) * Q_y * (V_y - P_y) = (1/2) * ((V_y - c) / 2)^2 = (V_y - c)^2 / 8$
    *   老年人的消费者剩余: $CS_o = (1/2) * Q_o * (V_o - P_o) = (1/2) * ((V_o - c) / 2)^2 = (V_o - c)^2 / 8$

---

#### **第二部分：二部定价 (Two-part Pricing)**

二部定价策略包含两部分：
1.  **准入费 (Entry Fee, A)**：一笔固定的费用，无论消费多少都必须支付，类似于会员费。
2.  **使用费 (Usage Fee, P)**：消费者为每单位产品或服务支付的价格。

为了实现利润最大化，厂商的理想策略是：
1.  将**使用费 $P$ 设定为等于边际成本 $c$** ($P = c$)。这样做可以鼓励消费者消费到社会最优水平，从而将整个潜在的消费者剩余最大化。
2.  将**准入费 $A$ 设定为在此价格下产生的全部消费者剩余**。

*   **计算消费者剩余 (当 P=c 时):**
    当 $P = c$ 时，我们将这个价格代入需求曲线来找到消费者会购买的数量。
    *   对老年人市场: $c = V_o - Q_o$  =>  $Q_o = V_o - c$
    *   此时的消费者剩余是一个更大的三角形，其面积为:
        $CS_o (at P=c) = (1/2) * (V_o - c) * (V_o - c) = (1/2)(V_o - c)^2$

*   **二部定价下的利润:**
    厂商的利润来自于准入费。因为使用费 $P$ 等于边际成本 $c$，所以每卖出一件产品，厂商在可变成本上不赚不赔。
    *   **策略**: 厂商可以将准入费 $A$ 设定为 $CS_o (at P=c)$。
    *   利润: $Profit = A - F = (1/2)(V_o - c)^2 - F$

    **重要说明**: 当存在两个不同需求的群体时，厂商面临一个选择。
    1.  **只服务高需求群体（老年人）**: 设定一个高准入费 $A = (1/2)(V_o - c)^2$。年轻人因准入费过高而不会购买。
    2.  **服务所有群体**: 必须设定一个较低的准入费，等于低需求群体（年轻人）的消费者剩余，即 $A = (1/2)(V_y - c)^2$。这样两个群体都会加入。总利润将是 $2 * A - F$。
    厂商会比较这两种策略的利润，选择更高的一种。模型原文在这里为了简化，只展示了针对一个群体（老年人）进行完美二部定价的情景。

#### **第三部分：区块定价 (Blocking Pricing)**

这部分实际上是对完美二部定价的另一种解释，两者在结果上是等价的。

*   **策略**: 厂商不把价格分为“准入费”和“使用费”，而是直接向消费者出售一个“产品包”或“消费区块”。
*   **计算**:
    1.  厂商让消费者以边际成本价 $c$ 消费，消费量为 $Q = V_o - c$。
    2.  厂商计算出消费者消费这么多数量时所获得的总价值（即需求曲线下方的全部面积）。这个总价值是 $(1/2)(V_o-c)^2$ (消费者剩余) + $c(V_o-c)$ (消费者实际支付的部分)。
    3.  厂商将整个“区块”打包，以这个总价值进行销售。
        *   总收入 (Total Revenue) = $(1/2)(V_o-c)^2 + c(V_o-c)$
    4.  总成本 (Total Cost) = 边际成本 × 数量 = $c * (V_o - c)$
    5.  利润 (Profit) = 总收入 - 总成本 - 固定成本 $F$
        $Profit = [(1/2)(V_o-c)^2 + c(V_o-c)] - c(V_o-c) - F$
        $Profit = (1/2)(V_o - c)^2 - F$

*   **结论**: $=> same with two-part pricing$
    这表明，完美的区块定价和完美的二部定价在利润结果上是完全相同的。它们都是旨在榨取全部消费者剩余的定价策略。

### **例题**

假设一个滑雪度假村面临两种类型的消费者：狂热的滑雪爱好者（老年人组，o）和偶尔来玩的游客（年轻人组，y）。他们的日票需求曲线分别为：
*   爱好者 (o): $P_o = 100 - Q_o$
*   游客 (y): $P_y = 60 - Q_y$

其中 $P$ 是每次滑雪的价格（美元），$Q$ 是每天滑雪的次数。度假村运营的边际成本 $c$ 为 20 美元。为了简化，我们假设固定成本 $F=0$。

**问题：**
1.  如果度假村对两组人收取不同的价格（第三方价格歧视），最优价格、数量和总利润是多少？
2.  如果度假村采用二部定价（例如，出售季票+每次滑雪费），最优策略和利润是什么？

---

**解答：**

**1. 标准垄断定价 (第三方价格歧视)**

*   **爱好者 (o) 市场:**
    *   $MR_o = 100 - 2Q_o$
    *   $MR_o = c$ => $100 - 2Q_o = 20$ => $2Q_o = 80$ => $Q_o = 40$
    *   $P_o = 100 - 40 = 60$
    *   $Profit_o = (P_o - c) * Q_o = (60 - 20) * 40 = 1600$ 美元

*   **游客 (y) 市场:**
    *   $MR_y = 60 - 2Q_y$
    *   $MR_y = c$ => $60 - 2Q_y = 20$ => $2Q_y = 40$ => $Q_y = 20$
    *   $P_y = 60 - 20 = 40$
    *   $Profit_y = (P_y - c) * Q_y = (40 - 20) * 20 = 400$ 美元

*   **总利润:**
    $Total Profit = Profit_o + Profit_y = 1600 + 400 = 2000$ 美元

**2. 二部定价**

度假村将每次滑雪的使用费设定为边际成本：$P = c = 20$ 美元。现在需要决定季票（准入费 $A$）的价格。

*   **计算在 $P=20$ 时各组的消费者剩余:**
    *   爱好者 (o):
        $20 = 100 - Q_o$ => $Q_o = 80$
        $CS_o = (1/2) * (100 - 20) * 80 = (1/2) * 80 * 80 = 3200$ 美元
    *   游客 (y):
        $20 = 60 - Q_y$ => $Q_y = 40$
        $CS_y = (1/2) * (60 - 20) * 40 = (1/2) * 40 * 40 = 800$ 美元

*   **度假村面临两种策略选择:**

    *   **策略A：只吸引爱好者。**
        设定高额季票 $A = CS_o = 3200$ 美元。只有爱好者会购买。
        $Profit_A = 3200$ 美元 (因为只有一个爱好者群体，假设每组只有1个代表性消费者)

    *   **策略B：吸引所有消费者。**
        必须设定一个较低的季票，让游客也愿意购买。$A = CS_y = 800$ 美元。
        此时，爱好者和游客都会购买季票。
        $Profit_B = (来自爱好者的准入费) + (来自游客的准入费) = 800 + 800 = 1600$ 美元
        (假设每组人数相同，这里简化为各一个消费者)

*   **决策:**
    比较两种策略的利润：$Profit_A = 3200$ 美元 > $Profit_B = 1600$ 美元。
    因此，度假村的最优二部定价策略是：
    *   设定每次滑雪费用 $P = 20$ 美元。
    *   出售价格为 $A = 3200$ 美元的季票。
    这个策略只吸引了狂热爱好者，但利润 (3200美元) 远高于之前的标准垄断定价 (2000美元)。

这个例子展示了二部定价如何通过榨取消费者剩余来为厂商带来更高的利润。
