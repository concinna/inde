### 模型详解

这个模型分析了在一个包含上游（输入品供应商）和下游（最终产品生产商）的市场中，当一家上游企业和一家下游企业发生垂直整合（合并）后，对市场竞争产生的影响。

#### 1. 模型设定

*   **市场参与者**:
    *   上游有两家企业：$U₁$ 和 $U₂$，它们生产同质的中间产品（输入品），生产的边际成本为 $cᵘ$。
    *   下游有两家企业：$D₁$ 和 $D₂$，它们利用上游的输入品生产最终产品，每单位输入品能生产一单位最终产品。下游企业自身的加工边际成本为 $cᴰ$。
*   **市场需求**: 最终产品的市场（反）需求函数为 $Pᴰ = A - B(q₁ + q₂)$. 其中 $Pᴰ$ 是最终产品的价格，$q₁$ 和 $q₂$ 分别是 $D₁$ 和 $D₂$ 的产量。
*   **核心事件**: 上游企业 $U₁$ 和下游企业 $D₁$ 合并，形成一个垂直整合的企业（我们称之为 $M₁$）。这导致下游企业 $D₂$ 只能从独立的上游供应商 $U₂$ 处购买输入品。
*   **竞争方式**:
    1.  上游企业 $U₂$ 为其输入品设定一个批发价格 $Pᵘ$。
    2.  下游的整合企业 $M₁$ (代表 $D₁$) 和独立企业 $D₂$ 进行**古诺竞争**（Cournot Competition），即同时选择自己的产量 $q₁$ 和 $q₂$。

#### 2. 成本结构分析

*   **整合企业 M₁ (D₁) 的成本**: 由于 $U₁$ 和 $D₁$ 已经合并，它不再需要从外部购买输入品。它的生产成本是内部转移的，等于上游生产成本加上下游加工成本。因此，其总边际成本为：
    $MC₁ = cᵘ + cᴰ$

*   **独立企业 D₂ 的成本**: $D₂$ 必须从 $U₂$ 购买输入品，价格为 $Pᵘ$。因此，其总边际成本为：
    $MC₂ = Pᵘ + cᴰ$

可以看到，整合企业 $M₁$ 拥有成本优势，因为它的输入品成本是 $cᵘ$，而其竞争对手 $D₂$ 的输入品成本是 $U₂$ 定的批发价 $Pᵘ$（通常 $Pᵘ > cᵘ$）。

#### 3. 下游古诺竞争均衡

下游两家企业进行古诺竞争，它们各自的利润函数为：
*   $π₁ᴰ = (Pᴰ - MC₁) * q₁ = (A - B(q₁ + q₂) - (cᵘ + cᴰ)) * q₁$
*   $π₂ᴰ = (Pᴰ - MC₂) * q₂ = (A - B(q₁ + q₂) - (Pᵘ + cᴰ)) * q₂$

通过对各自产量求一阶导数（利润最大化），可以解出均衡产量。在标准的古诺模型中，均衡产量为：
*   $q₁ = (A - 2*MC₁ + MC₂) / 3B$
*   $q₂ = (A - 2*MC₂ + MC₁) / 3B$

将 $MC₁$ 和 $MC₂$ 代入，标准解应为：
*   $q₁ = (A - 2(cᵘ + cᴰ) + (Pᵘ + cᴰ)) / 3B = (A - 2cᵘ - cᴰ + Pᵘ) / 3B$
*   $q₂ = (A - 2(Pᵘ + cᴰ) + (cᵘ + cᴰ)) / 3B = (A - 2Pᵘ - cᴰ + cᵘ) / 3B$

**【重要提示】**: 您提供的笔记中，此处的公式分母为 $9B$，这与标准古诺模型推导出的$3B$不同。这可能是笔记作者的笔误，或者是该模型基于某个未明确说明的、更复杂的前提。为了忠实解释您提供的模型，我们接下来将**沿用笔记中的公式**进行分析。

根据笔记中的公式：
$$
q _ { 1 } ^ { D } = \frac { A - 2 ( c ^ { u } + c ^ { D } ) + ( P ^ { u } + c ^ { D } ) } { 9 B } = \frac { A - 2 c ^ { u } - c ^ { D } + P ^ { u } } { 9 B }
$$
$$
q _ { 2 } ^ { D } = \frac { A - 2 ( P ^ { u } + c ^ { D } ) + ( c ^ { u } + c ^ { D } ) } { 9 B } = \frac { A - 2 P ^ { u } - c ^ { D } + c ^ { u } } { 9 B }
$$
对应的利润为：
$$
\pi _ { 1 } ^ { D } = \frac { ( A - 2 c ^ { u } - c ^ { D } + P ^ { u } ) ^ { 2 } } { 9 B }
$$
$$
\pi _ { 2 } ^ { D } = \frac { ( A - 2 P ^ { u } - c ^ { D } + c ^ { u } ) ^ { 2 } } { 9 B }
$$
此时，$Pᵘ$ 尚未确定，所以 $D₁$ 和 $D₂$ 的产量和利润还都是 $Pᵘ$ 的函数。

笔记中观察到：当 $Pᵘ$ 上升时，$q₁ᴰ$ 上升，而 $q₂ᴰ$ 下降。这是因为 $Pᵘ$ 的上升提高了 $D₂$ 的成本，使其在竞争中处于劣势，产量下降；而 $M₁$ (D₁) 则利用这个机会扩大自己的产量。

#### 4. 上游垄断企业 U₂ 的定价决策

现在我们分析 $U₂$ 如何定价。$U₂$ 知道 $D₂$ 对其输入品的需求量就是 $D₂$ 的最终产量，即 $q₂ᵘ = q₂ᴰ$。因此，$U₂$ 面临的需求曲线就是由 $q₂ᴰ$ 的公式反解出来的 $Pᵘ$ 和 $q₂$ 的关系。

从 $q₂ᴰ$ 的公式出发：
$q₂ᴰ = (A - 2Pᵘ - cᴰ + cᵘ) / 9B$

反解出 $Pᵘ$：
$9B * q₂ᴰ = A - cᴰ + cᵘ - 2Pᵘ$
$2Pᵘ = A - cᴰ + cᵘ - 9B * q₂ᴰ$
$Pᵘ = (A - cᴰ + cᵘ) / 2 - (9B / 2) * q₂ᴰ$

这构成了 $U₂$ 面临的反需求函数 $P(q)$，形式为 $P = a - bq$，其中：
*   $a = (A - cᴰ + cᵘ) / 2$
*   $b = 9B / 2$

**【再次提示】**: 笔记在这里似乎将分母$9B$修正为了$3B$，写成了 $b = 3B / 2$。这进一步表明初始的$9B$可能是笔误。我们继续跟随笔记的逻辑。

$U₂$ 的目标是最大化其利润 $π₂ᵘ = (Pᵘ - cᵘ) * q₂ᵘ$。对于线性需求，边际收益 $MR = a - 2bq$。令边际收益等于边际成本 $cᵘ$：
$(A - cᴰ + cᵘ) / 2 - 2 * (3B / 2) * q₂ᵘ = cᵘ$
$(A - cᴰ + cᵘ) / 2 - 3B * q₂ᵘ = cᵘ$
$3B * q₂ᵘ = (A - cᴰ + cᵘ) / 2 - cᵘ = (A - cᴰ - cᵘ) / 2$
$q₂ᵘ = (A - cᴰ - cᵘ) / 6B$

将此最优产量 $q₂ᵘ$ (即 $q₂ᴰ$) 代回 $U₂$ 的反需求函数，得到最优批发价 $Pᵘ$。笔记中直接给出了最终结果（这些结果可能基于其内部的、未完全展示的计算过程）：

*   最优批发价：
    $$
    P ^ { u } = \frac { A + 3 c ^ { u } - c ^ { D } } { 4 }
    $$
*   $U₂$ 的利润：
    $$
    \pi _ { 2 } ^ { u } = \frac { ( A - c ^ { u } - c ^ { D } ) ^ { 2 } } { 4 B }
    $$
*   均衡时的下游产量：
    $$
    q _ { 1 } ^ { D } = \frac { 5( A - c ^ { u } - c ^ { D } ) } { 12 B } \quad (\text{笔记中此公式有误，这里是根据利润公式反推的正确形式})
    $$
    $$
    q _ { 2 } ^ { D } = \frac { ( A - c ^ { u } - c ^ { D } ) } { 6 B }
    $$

#### 5. 最终市场均衡结果

将均衡的 $Pᵘ$ 代入下游的产量和利润公式，可以得到市场的最终均衡。笔记中给出了以下最终结果：

*   最终产品市场价格:
    $$
    P ^ { D } = \frac { 5 A + 7 c ^ { u } + 7 c ^ { D } } { 12 }
    $$
*   整合企业 $M₁$ (D₁) 的利润:
    $$
    \pi _ { 1 } ^ { D } = \frac { 25 ( A - c ^ { u } - c ^ { D } ) ^ { 2 } } { 144 B }
    $$
*   独立企业 $D₂$ 的利润:
    $$
    \pi _ { 2 } ^ { D } = \frac { ( A - c ^ { u } - c ^ { D } ) ^ { 2 } } { 36 B }
    $$

#### 6. 核心问题：市场排斥（Foreclosure）的动机分析

模型最后探讨了一个关键问题：**整合企业 M₁ 完全拒绝向其竞争对手 D₂ 供应输入品（即市场排斥）是否有利可图？**

笔记中的逻辑如下：
假设整合企业可以将一单位输入品卖给 $D₂$，也可以自己用来生产最终产品。它需要比较这两种选择的收益。

1.  **将输入品卖给 D₂ 的收益**: 这个收益在笔记中被写为 $Pᵘ - cᵘ$（即在上游市场赚取的利润）。
2.  **自己使用输入品并销售最终产品的收益**: 笔记中将此收益写为 $Pᴰ - (Pᵘ + cᴰ)$。这一步的逻辑比较费解且可能不准确。更标准的逻辑是，自己使用该输入品生产最终产品的边际利润是 $Pᴰ - (cᵘ + cᴰ)$。

我们先跟随笔记的逻辑。它认为，如果不卖给下游竞争对手是更有利可图的，那么必须满足：
$自己使用的收益 > 卖给对手的收益$
$$
P ^ { D } - ( P ^ { u } + c ^ { D } ) > P ^ { u } - c ^ { u }
$$
这个不等式被笔记错误地简化为 $Pᴰ > Pᵘ + cᴰ$。实际上，它应该化简为 $Pᴰ + cᵘ > 2Pᵘ + cᴰ$。

然而，笔记的最终验证步骤使用了另一个不等式：
$$
\frac { A - ( c ^ { u } + c ^ { D } ) } { 6 } > 0
$$
这个不等式只要市场存在（即需求 $A$ 大于总边际成本 $cᵘ + cᴰ$），就**恒成立**。

**结论**: 尽管推导过程存在一些跳跃和不一致，但该模型的核心结论是，**垂直整合后的企业有动机去实施市场排斥**。它可以通过拒绝供货或以非常高的价格供货（称为“抬高竞争对手成本”，Raising Rivals' Costs）来削弱其下游竞争对手，从而使自身获利。

### 例题

假设市场需求和成本参数如下：
*   市场需求参数: $A = 120$, $B = 1$
*   上游生产成本: $cᵘ = 10$
*   下游加工成本: $cᴰ = 10$

我们使用模型中的最终公式来计算均衡结果。

**1. 计算上游批发价 $Pᵘ$**
$$
P ^ { u } = \frac { A + 3 c ^ { u } - c ^ { D } } { 4 } = \frac { 120 + 3(10) - 10 } { 4 } = \frac { 140 } { 4 } = 35
$$
$U₂$ 会以 35 元的价格向 $D₂$ 出售输入品，这远高于其成本 10 元。

**2. 计算下游企业的产量 $q₁ᴰ$ 和 $q₂ᴰ$**
*   整合企业 $M₁$ (D₁) 的产量:
    $$
    q _ { 1 } ^ { D } = \frac { 5 ( A - c ^ { u } - c ^ { D } ) } { 12 B } = \frac { 5 ( 120 - 10 - 10 ) } { 12 \times 1 } = \frac { 5 \times 100 } { 12 } \approx 41.67
    $$
*   独立企业 $D₂$ 的产量:
    $$
    q _ { 2 } ^ { D } = \frac { ( A - c ^ { u } - c ^ { D } ) } { 6 B } = \frac { 120 - 10 - 10 } { 6 \times 1 } = \frac { 100 } { 6 } \approx 16.67
    $$
可以看到，整合企业的产量远大于其竞争对手。

**3. 计算最终产品市场价格 $Pᴰ$**
$$
P ^ { D } = \frac { 5 A + 7 c ^ { u } + 7 c ^ { D } } { 12 } = \frac { 5(120) + 7(10) + 7(10) } { 12 } = \frac { 600 + 70 + 70 } { 12 } = \frac { 740 } { 12 } \approx 61.67
$$

**4. 计算各企业的利润**
*   整合企业 $M₁$ (D₁) 的利润:
    $$
    \pi _ { 1 } ^ { D } = \frac { 25 ( A - c ^ { u } - c ^ { D } ) ^ { 2 } } { 144 B } = \frac { 25 ( 100 ) ^ { 2 } } { 144 } = \frac { 250000 } { 144 } \approx 1736.11
    $$
*   独立企业 $D₂$ 的利润:
    $$
    \pi _ { 2 } ^ { D } = \frac { ( A - c ^ { u } - c ^ { D } ) ^ { 2 } } { 36 B } = \frac { ( 100 ) ^ { 2 } } { 36 } = \frac { 10000 } { 36 } \approx 277.78
    $$
*   上游企业 $U₂$ 的利润:
    $$
    \pi _ { 2 } ^ { u } = (P^u - c^u) \times q_2^D = (35 - 10) \times 16.67 = 25 \times 16.67 \approx 416.75
    $$
    （使用公式计算：$π₂ᵘ = (A - cᵘ - cᴰ)² / 4B = 100² / (4*1) = 2500$。这里公式之间存在巨大差异，再次说明笔记的推导不一致。我们以分步计算为准。）

**5. 验证市场排斥动机**
我们使用笔记最后的条件进行验证：
$$
\frac { A - ( c ^ { u } + c ^ { D } ) } { 6 } > 0
$$
$$
\frac { 120 - ( 10 + 10 ) } { 6 } = \frac { 100 } { 6 } \approx 16.67 > 0
$$
该条件成立，表明在这个算例中，整合企业确实有动机去排斥其竞争对手。

这个模型虽然在数学推导上可能存在一些瑕疵，但它清晰地揭示了垂直整合在产业组织理论中的一个核心议题：**整合可能不仅仅是为了提高效率，也可能成为一种排斥竞争对手、增强市场势力的策略性工具**。
