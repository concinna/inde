好的，这是一个非常经典和核心的微观经济学模型，对比了**完全竞争市场 (Perfect Competition)** 和 **垄断市场 (Monopoly)** 中厂商的决策行为。下面我将对模型进行详细的中文解释，保留所有公式，并给出一道新的例题。

---

### 模型详解

这个模型的核心是分析在不同市场结构下，追求利润最大化的厂商如何决定其产量和价格。

#### 1. 完全竞争市场 (Perfectly Competitive)

在完全竞争市场中，存在大量的买者和卖者，产品同质，信息完全，厂商可以自由进出市场。最重要的特征是：**单个厂商是价格的接受者 (price taker)**，无法影响市场价格。

**利润最大化的一阶条件 (First-Order Condition, FOC):**

一个厂商 $i$ 的利润 $πᵢ$ 是总收益 $P * qᵢ$ 减去总成本 $c(qᵢ)$。由于市场价格 $P$ 对单个厂商来说是给定的常数，其利润最大化问题是：
$max πᵢ = P * qᵢ - c(qᵢ)$

为了求最大值，我们对产量 $qᵢ$ 求一阶导数并使其等于零：
$dπᵢ / dqᵢ = P - c'(qᵢ) = 0$

这就得到了完全竞争厂商的利润最大化条件：

$$ P = c'(q_i) $$

*   **P**: 市场价格 (Price)。
*   **c'(qᵢ)**: 厂商 $i$ 的边际成本 (Marginal Cost, MC)，即生产最后一单位产品所增加的成本。

**释义**:
这个公式的经济学含义是，一个完全竞争厂商会持续生产，直到生产最后一单位产品的边际成本恰好等于该产品所能卖出的市场价格。如果 $P > MC$，厂商增加产量还能赚钱；如果 $P < MC$，生产最后一单位会亏钱，厂商应该减产。

**行业供给曲线 (Industry Supply):**

行业供给曲线是所有单个厂商供给曲线的水平加总。
首先，从 $P = cᵢ'(qᵢ)$ 中，我们可以反解出每个厂商在给定价格 $P$ 下愿意生产的产量 $qᵢ$：

$$ q_i = c_i'^{-1}(p) $$

这里 $cᵢ'⁻¹(p)$ 是边际成本函数的反函数。然后，将所有厂商的产量加总，就得到了整个市场的总供给量 $Q*$：

$$ Q^* = \sum_{i=1}^{n} q_i = \sum_{i=1}^{n} c_i'^{-1}(p) = F(p) $$

这条曲线 $Q* = F(p)$ 就是行业的供给曲线，它表示在每个价格水平上，整个行业愿意供给的总产量。

---

#### 2. 垄断市场 (Monopoly)

垄断市场只有一个卖者，该卖者是**价格的制定者 (price maker)**。它面对的是整个市场的需求曲线，通常是向下倾斜的。这意味着垄断者要想卖出更多的产品，就必须降低价格。

**利润最大化的一阶条件:**

垄断者的利润 $π$ 是总收益 $TR$ 减去总成本 $TC$。
$π = TR(Q) - TC(Q) = P(Q) * Q - c(Q)$
注意这里的价格 $P$ 是产量 $Q$ 的函数 $P(Q)$，因为垄断者改变产量会影响价格。

对 $Q$ 求一阶导数并令其为零：
$dπ / dQ = d(P(Q) * Q)/dQ - c'(Q) = 0$

使用乘法法则对 $P(Q) * Q$ 求导：
$d(P(Q) * Q)/dQ = (dP/dQ) * Q + P * (dQ/dQ) = P'(Q)Q + P$

这个 $P'(Q)Q + P$ 就是**边际收益 (Marginal Revenue, MR)**。因此，垄断者的利润最大化条件是 **MR = MC**:

$$P'(Q)Q + P = c'(Q)$$

*   **P'(Q)Q + P**: 边际收益 (MR)。
*   **c'(Q)**: 边际成本 (MC)。

**MR 与 P 的关系**:
由于需求曲线向下倾斜，$P'(Q) = dP/dQ < 0$。这意味着 $P'(Q)Q$ 这一项是负数。因此，对于垄断者来说：
**MR = P + P'(Q)Q < P**

**释义**:
垄断者的边际收益总是低于其产品的售价。这是因为当它决定多卖一单位产品时，它不仅要为这新增的一单位产品设定一个较低的价格，还必须对**之前所有**原本可以高价卖出的产品都降价销售。这个对存量单位的降价损失，使得边际收益小于价格。

#### 3. 弹性分析 (An Alternative way: elasticity)

这是一种更通用的方法，可以将上述两种情况统一起来。

需求价格弹性 $ε$ 的定义是：
$$ \varepsilon = - \frac{\partial Q}{\partial p} \frac{p}{Q} $$

垄断者的利润最大化条件 $P'(Q)Q + P = c'(Q)$ 可以变形为：
$P - c' = -P'(Q)Q$

两边同时除以 $P$：
$$ \frac{P - c'}{P} = - \frac{P'(Q)Q}{P} = - \frac{dQ}{dp} \frac{Q}{P} $$

注意到 $P'(Q) = dp/dQ$，所以 $-P'(Q) = -dp/dQ = 1 / (dQ/dp)$。代入上式：
$$ \frac{P - c'}{P} = \frac{1}{\frac{\partial Q}{\partial p} \frac{p}{Q}} = \frac{1}{\varepsilon} $$

这个公式被称为**勒纳指数 (Lerner Index)**，它衡量了厂商的市场势力（定价能力）。
从这个公式可以推导出价格和边际成本的关系：
$$ p(1 - \frac{1}{\varepsilon}) = c' \Rightarrow p = \left(\frac{\varepsilon}{\varepsilon - 1}\right) c' $$

*   **在垄断市场中**: $ε$ 是一个有限的正数（且 $ε > 1$，因为垄断者总是在需求曲线的弹性部分经营）。$ε / (ε - 1)$ 大于 1，所以 $P > c'$。需求弹性 $ε$ 越小（消费者对价格越不敏感），$ε / (ε - 1)$ 的值就越大，垄断者定的价格 $P$ 相对于边际成本 $c'$ 就越高。

*   **在完全竞争市场中**: 单个厂商面对的是一条水平的需求曲线，意味着需求有**无限弹性 (perfectly elastic)**，即 $ε → ∞$。
    将 $ε → ∞$ 代入公式：
    $$ \frac{P - c'}{P} = \frac{1}{\infty} = 0 \Rightarrow P - c' = 0 \Rightarrow P = c' $$
    这与我们之前得到的完全竞争市场结论完全一致。

### 例题详解

原文中已经给出了一个垄断市场的例子，我们来给出一个**完全竞争市场**的例子，并与垄断进行对比，以便更好地理解二者的区别。

假设一个市场的需求曲线和成本状况如下：

*   **市场需求曲线 (Market Demand)**: $Q = 1000 - 20P$
*   **行业边际成本 (Marginal Cost)**: $MC = 10$ (为简化，假设所有厂商的边际成本都是常数10，这也是行业的供给曲线)

**问题：**
1.  如果该市场是**完全竞争**的，均衡价格和产量是多少？
2.  如果该市场被一个**垄断者**控制，垄断价格和产量是多少？
3.  对比两种情况的结果。

---

#### 解答

**1. 完全竞争市场 (Perfect Competition)**

**目标函数**: 在完全竞争市场中，均衡点是市场供给与市场需求相交之处。均衡条件是**价格等于边际成本 (P = MC)**。

*   **供给**: 行业的供给曲线由边际成本决定。由于 $MC = 10$，这意味着无论产量多少，提供一单位产品的边际成本都是10。所以，行业的供给曲线是一条在 $P = 10$ 处的水平线。
*   **均衡**: 设定市场价格 $P$ 等于边际成本 $MC$。
    $P_c = MC = 10$

    将均衡价格 $P_c = 10$ 代入市场需求曲线，求出均衡产量 $Q_c$：
    $Q_c = 1000 - 20 * P_c$
    $Q_c = 1000 - 20 * (10)$
    $Q_c = 1000 - 200 = 800$

**结论**: 在完全竞争市场下，均衡价格为 **10**，均衡产量为 **800**。

**2. 垄断市场 (Monopoly)**

**目标函数**: 垄断者追求自身利润最大化，其决策准则是**边际收益等于边际成本 (MR = MC)**。

*   **第一步：求边际收益 (MR)**
    首先，我们需要从需求曲线 $Q = 1000 - 20P$ 中得到反需求曲线（即 $P$ 关于 $Q$ 的函数）：
    $20P = 1000 - Q$
    $P = 50 - (1/20)Q$

    然后，计算总收益 (TR)：
    $TR = P * Q = (50 - (1/20)Q) * Q = 50Q - (1/20)Q²$

    对总收益 $TR$ 求关于 $Q$ 的导数，得到边际收益 $MR$：
    $MR = d(TR)/dQ = 50 - 2 * (1/20)Q = 50 - (1/10)Q$
    *(一个有用的技巧：对于线性需求曲线 P = a - bQ，其边际收益曲线为 MR = a - 2bQ，截距相同，斜率是两倍)*

*   **第二步：令 MR = MC**
    我们已知 $MC = 10$。
    $50 - (1/10)Q_m = 10$
    $(1/10)Q_m = 40$
    $Q_m = 400$

*   **第三步：求垄断价格 (P_m)**
    将垄断产量 $Q_m = 400$ 代入反需求曲线：
    $P_m = 50 - (1/20) * Q_m$
    $P_m = 50 - (1/20) * (400)$
    $P_m = 50 - 20 = 30$

**结论**: 在垄断市场下，垄断产量为 **400**，垄断价格为 **30**。

**3. 对比分析**

| | 完全竞争 (Perfect Competition) | 垄断 (Monopoly) |
| :--- | :---: | :---: |
| **价格 (Price)** | P_c = 10 | P_m = 30 |
| **产量 (Quantity)** | Q_c = 800 | Q_m = 400 |

通过对比可以清晰地看到：
*   **垄断导致更高的价格** ($30 > 10$)。
*   **垄断导致更低的产量** ($400 < 800$)。

这就是垄断造成的**经济效率损失**或**无谓损失 (Deadweight Loss)**。垄断者为了最大化自身利润，会限制产量并抬高价格，这使得一部分原本在完全竞争市场下可以成交的、对社会有效率的交易（即消费者的支付意愿高于生产的边际成本）无法发生，从而损害了社会总福利。
