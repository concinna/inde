### **斯塔克尔伯格模型（Stackelberg Model）详解**

斯塔克尔伯格模型是一种双寡头（duopoly）市场模型，用于描述两家公司在产量上的竞争。与古诺（Cournot）模型最大的不同在于，斯塔克尔伯格模型是一个**序贯博弈（Sequential Game）**，而古诺模型是**同时博弈（Simultaneous Game）**。

在斯塔克尔伯格模型中，市场上有两家公司：
1.  **领导者（Leader）**：首先决定其产量的公司。
2.  **追随者（Follower）**：在观察到领导者的产量后，再决定自己的产量的公司。

这个模型的核心是“先行者优势”（First-Mover Advantage）。领导者在做决策时，能够预见到追随者将如何对自己的产量做出最优反应，并将这种反应纳入自己的利润最大化计算中。

#### **核心假设**
*   市场中有两家公司（企业1为领导者，企业2为追随者）。
*   产品是同质的（完全相同）。
*   公司通过选择产量进行竞争。
*   决策有先后顺序：领导者先选，追随者后选。
*   信息是完全的：追随者知道领导者的产量，领导者知道追随者的反应模式。

### **模型求解与公式解析**

我们从一个一般的线性需求和成本结构开始，这与您笔记中的例子一致。

假设市场逆向需求函数为：
$ P = A - B \cdot Q $，其中 $ Q = q_L + q_F $ 是市场总产量（$q_L$ 为领导者产量，$q_F$ 为追随者产量）。
假设两家公司的边际成本（Marginal Cost, MC）都为常数 $c$。

#### **第一步：求解追随者（Follower）的最优反应**

追随者观察到领导者的产量 $q_L$ 后，将其视为一个给定的常数。它的目标是选择自己的产量 $q_F$ 来最大化自身利润 $ \pi_F $。

追随者的利润函数为：
$ \pi_F = P \cdot q_F - c \cdot q_F = (A - B(q_L + q_F)) \cdot q_F - c \cdot q_F $
$ \pi_F = A \cdot q_F - B \cdot q_L \cdot q_F - B \cdot q_F^2 - c \cdot q_F $

为了最大化利润，我们将 $ \pi_F $ 对 $q_F$ 求导，并令其等于零：
$ \frac{\partial \pi_F}{\partial q_F} = A - B \cdot q_L - 2B \cdot q_F - c = 0 $

整理上式，我们可以得到追随者的**反应函数（Reaction Function）**：
$ 2B \cdot q_F = A - c - B \cdot q_L $
$ q_F = \frac{A - c}{2B} - \frac{1}{2} q_L $

这个公式告诉我们，对于领导者选择的任何产量 $q_L$，追随者的最优产量 $q_F$ 是多少。这与您笔记中的公式 $ q _ { F } = \frac { A - C } { 2 a } - \frac { q _ { L } } { 2 } $ 形式完全一致（只是字母表示不同）。

#### **第二步：求解领导者（Leader）的最优决策**

领导者非常聪明，它知道追随者会根据上述反应函数来行动。因此，领导者在选择自己的产量 $q_L$ 时，会把追随者的反应代入自己的利润函数中。

领导者的利润函数为：
$ \pi_L = P \cdot q_L - c \cdot q_L = (A - B(q_L + q_F)) \cdot q_L - c \cdot q_L $

现在，将追随者的反应函数 $ q_F = \frac{A - c}{2B} - \frac{1}{2} q_L $ 代入上式：
$ \pi_L = \left( A - B \left( q_L + \left( \frac{A - c}{2B} - \frac{1}{2} q_L \right) \right) \right) \cdot q_L - c \cdot q_L $
$ \pi_L = \left( A - B \left( \frac{1}{2} q_L + \frac{A - c}{2B} \right) \right) \cdot q_L - c \cdot q_L $
$ \pi_L = \left( A - \frac{B}{2} q_L - \frac{A - c}{2} \right) \cdot q_L - c \cdot q_L $
$ \pi_L = \left( \frac{A - c}{2} - \frac{B}{2} q_L \right) \cdot q_L - c \cdot q_L $  
*(这里有一个小错误，上面的推导最后一步是不需要 $- c*q_L$ 的，因为 $(A-c)/2$ 已经包含了成本，我们重新整理一下)*

我们先代入到价格 P 中：
$ P = A - B(q_L + q_F) = A - B(q_L + \frac{A-c}{2B} - \frac{1}{2}q_L) = A - B(\frac{1}{2}q_L + \frac{A-c}{2B}) = A - \frac{B}{2}q_L - \frac{A-c}{2} = \frac{A+c}{2} - \frac{B}{2}q_L $

现在计算领导者利润：
$ \pi_L = (P - c) \cdot q_L = \left( (\frac{A+c}{2} - \frac{B}{2}q_L) - c \right) \cdot q_L = \left( \frac{A-c}{2} - \frac{B}{2}q_L \right) \cdot q_L $
$ \pi_L = \frac{A-c}{2} q_L - \frac{B}{2} q_L^2 $

为了最大化利润，我们将 $ \pi_L $ 对 $q_L$ 求导，并令其等于零：
$ \frac{\partial \pi_L}{\partial q_L} = \frac{A-c}{2} - B \cdot q_L = 0 $

解得领导者的最优产量：
$ q_L^* = \frac{A-c}{2B} $

#### **第三步：求解均衡结果**

我们已经得到了领导者的最优产量 $q_L^*$。现在，将其代入追随者的反应函数，得到追随者的最优产量 $q_F^*$:
$ q_F^* = \frac{A - c}{2B} - \frac{1}{2} q_L^* = \frac{A - c}{2B} - \frac{1}{2} \left( \frac{A-c}{2B} \right) = \frac{A-c}{4B} $

**均衡结果总结：**
*   领导者产量：$ q_L^* = \frac{A-c}{2B} $
*   追随者产量：$ q_F^* = \frac{A-c}{4B} $
*   市场总产量：$ Q_S = q_L^* + q_F^* = \frac{A-c}{2B} + \frac{A-c}{4B} = \frac{3(A-c)}{4B} $
*   市场价格：$ P_S = A - B \cdot Q_S = A - B \left( \frac{3(A-c)}{4B} \right) = \frac{A+3c}{4} $

### **与古诺模型的比较及效率讨论**

您提供的笔记很好地总结了这一点。我们来验证一下。

*   **古诺模型（Cournot Model）**：两家公司同时决策，最终达到纳什均衡。其总产量为 $ Q_C = \frac{2(A-c)}{3B} $。
*   **完全竞争（Perfect Competition）**：价格等于边际成本，$P=c$。此时总产量 $ Q_{PC} = \frac{A-c}{B} $。

**产量比较**：
*   斯塔克尔伯格总产量：$ Q_S = \frac{3}{4} \frac{A-c}{B} = \frac{3}{4} Q_{PC} $ (完全竞争产量的 3/4)
*   古诺总产量：$ Q_C = \frac{2}{3} \frac{A-c}{B} = \frac{2}{3} Q_{PC} $ (完全竞争产量的 2/3)

因为 $ \frac{3}{4} > \frac{2}{3} $，所以 $ Q_S > Q_C $。
这意味着斯塔克尔伯格模型的**总产量更高**，从而**市场价格更低**。

**效率（Efficiency）讨论**：
从社会福利的角度看，产量越高、价格越接近边际成本，市场就越有效率（消费者剩余更大，总剩余也更大）。由于斯塔克尔伯格模型的总产量比古诺模型更接近完全竞争水平，因此可以认为**斯塔克尔伯格模型比古诺模型更有效率**。

**先行者优势 vs 后行者优势**：
笔记中提到“a firm prefers being a follower”。这一点在标准的**产量竞争**模型（如斯塔克尔伯格）中是**错误**的。
*   在斯塔克尔伯格产量竞争中，领导者的利润 $ \pi_L = \frac{(A-c)^2}{8B} $，追随者的利润 $ \pi_F = \frac{(A-c)^2}{16B} $，而古诺均衡中每个公司的利润是 $ \pi_C = \frac{(A-c)^2}{9B} $。
*   我们可以看到 $ \pi_L > \pi_C > \pi_F $。因此，公司**总是更愿意成为领导者**，而不是追随者。这就是“先行者优势”。
*   笔记中提到的“追随者可以搭便车”的直觉更适用于**价格竞争**模型（伯特兰模型），在某些条件下可能存在“后发优势”。

### **例题解析（基于您笔记中的实验数据）**

这里我们使用您笔记中提到的 Huck, Muller & Norman (2001) 的实验设定，来求解一个具体的例子。

**题目**：
市场逆向需求函数为 $ P = 30 - Q $，其中 $ Q = q_1 + q_2 $。两家公司的边际成本均为常数 $ MC = 6 $。
1.  求解古诺均衡下的产量和利润。
2.  求解斯塔克尔伯格均衡下的产量和利润（假设企业1是领导者）。
3.  比较两个模型的结果。

**解答**：

**1. 古诺均衡**

*   企业1的反应函数：$ \pi_1 = (30 - q_1 - q_2)q_1 - 6q_1 $。求导得 $ q_1 = 12 - 0.5q_2 $。
*   由于两家公司对称，企业2的反应函数为：$ q_2 = 12 - 0.5q_1 $。
*   联立求解：$ q_1 = 12 - 0.5(12 - 0.5q_1) \Rightarrow q_1 = 12 - 6 + 0.25q_1 \Rightarrow 0.75q_1 = 6 \Rightarrow q_1 = 8 $。
*   因此，$ q_1 = q_2 = 8 $。这与您笔记中的理论预测“cournot: 8 vs 8”完全一致。
*   总产量 $ Q_C = 8 + 8 = 16 $。
*   价格 $ P_C = 30 - 16 = 14 $。
*   利润 $ \pi_1 = \pi_2 = (14 - 6) \times 8 = 64 $。

**2. 斯塔克尔伯格均衡**

*   **追随者（企业2）的决策**：企业2的反应函数我们已经在上面算过了，就是 $ q_2 = 12 - 0.5q_1 $。这与您笔记中的公式 $ q _ { F } = 1 2 - 0 . 5 q _ { L } $ 完全一致。

*   **领导者（企业1）的决策**：领导者将企业2的反应代入自己的利润函数。
    $ \pi_1 = (30 - q_1 - q_2)q_1 - 6q_1 $
    $ \pi_1 = (30 - q_1 - (12 - 0.5q_1))q_1 - 6q_1 $
    $ \pi_1 = (18 - 0.5q_1)q_1 - 6q_1 $
    $ \pi_1 = 18q_1 - 0.5q_1^2 - 6q_1 = 12q_1 - 0.5q_1^2 $
    对 $q_1$ 求导并令其为0：
    $ \frac{\partial \pi_1}{\partial q_1} = 12 - q_1 = 0 \Rightarrow q_1 = 12 $。

*   **均衡结果**：
    *   领导者产量：$ q_L = 12 $。
    *   将 $q_L=12$ 代入追随者反应函数：$ q_F = 12 - 0.5 \times 12 = 6 $。
    *   这与您笔记中的理论预测“stackelberg is to produce Leader:12 follower:6”完全一致。
    *   总产量 $ Q_S = 12 + 6 = 18 $。
    *   价格 $ P_S = 30 - 18 = 12 $。
    *   领导者利润 $ \pi_L = (12 - 6) \times 12 = 72 $。
    *   追随者利润 $ \pi_F = (12 - 6) \times 6 = 36 $。

**3. 结果比较**

| 指标 | 古诺模型 | 斯塔克尔伯格模型 |
| :--- | :--- | :--- |
| **总产量** | 16 | **18** (更高) |
| **价格** | 14 | **12** (更低) |
| **企业1利润** | 64 | **72 (领导者)** |
| **企业2利润** | 64 | **36 (追随者)** |
| **总利润** | 128 | 108 |

比较结果验证了理论：斯塔克尔伯格模型总产量更高，价格更低，社会效率更高。同时，领导者利润高于古诺均衡，追随者利润低于古诺均衡，体现了“先行者优势”。

### **行为经济学视角：不平等厌恶（Inequality Aversion）**

您的笔记最后一部分非常有价值，它解释了为什么**实验结果**与**理论预测**可能存在偏差。

*   **实验发现**：回归结果 $ q _ { F } = 1 0 . 2 7 5 - 0 . 1 7 8 q _ { L } $ 显示，追随者的实际行为比理论预测的 $ q _ { F } = 1 2 - 0 . 5 q _ { L } $ “更具攻击性”（即对于给定的 $q_L$，他们的产量 $q_F$ 更高）。

*   **理论解释：不平等厌恶**
    实验者提出，追随者可能不仅仅关心自己的绝对利润（$ \pi_F $），还关心与领导者之间的利润差距。他们引入了一个包含“不平等厌恶”的效用函数：
    $ u = \pi _ { F } - \alpha \operatorname* { m a x } ( \pi _ { L } - \pi _ { F } , 0 ) - \beta \operatorname* { m a x } ( \pi _ { F } - \pi _ { L } , 0 ) $
    *   $u$ 是追随者的总效用。
    *   $ \pi_F $ 是追随者的利润。
    *   $ \alpha $ 是对“不利不平等”（自己赚得比别人少）的厌恶系数。当 $ \pi_L > \pi_F $ 时，这一项为负，降低总效用。
    *   $ \beta $ 是对“有利不平等”（自己赚得比别人多）的厌恶系数（通常 $ \alpha > \beta $，人们更讨厌自己吃亏）。

*   **直觉解释**：
    在斯塔克尔伯格模型中，领导者的利润总是远高于追随者（$ \pi_L > \pi_F $）。一个具有不平等厌恶的追随者，可能会愿意牺牲一点自己的利润（$ \pi_F $ 降低），来大幅拉低领导者的利润（$ \pi_L $ 大幅降低），从而缩小两者之间的差距（$ \pi_L - \pi_F $ 减小）。
    如何做到这一点？**增加产量**。
    当追随者增加产量 $q_F$ 时：
    1.  市场总产量 $Q$ 上升，导致价格 $P$ 下降。
    2.  价格下降对双方都有害。但由于领导者的产量 $q_L$ 更大，所以价格下降对领导者利润的损害也更大。
    3.  虽然追随者自己的利润可能也会过最优点而略有下降，但由于不平等差距的缩小给他带来了效用上的满足，这种“惩罚”领导者的行为在整体上可能是“理性”的。

*   **笔记中的数值例子**：
    当领导者产量 $q_L = 10.19$ 时：
    *   理论上，追随者应生产 $ q_F = 12 - 0.5(10.19) \approx 6.9 $。
    *   此时价格 $P = 30 - (10.19+6.9) = 12.91$。
    *   利润为 $ \pi_L = (12.91-6) \times 10.19 \approx 70.41 $ 和 $ \pi_F = (12.91-6) \times 6.9 \approx 47.68 $。
    *   利润差 $ \pi_L - \pi_F = 22.73 $。

    一个有不平等厌恶的追随者，可能会选择生产 $q_F = 7.5$。这会使价格进一步下降，可能导致 $ \pi_F $ 从 47.68 降到 47，但 $ \pi_L $ 可能从 70.41 大幅降到 65。虽然自己的利润少了0.68，但利润差缩小了超过5，这可能会让他的总效用 $u$ 增加。这就解释了为什么实验中的追随者会比理论预测的产量更高。
