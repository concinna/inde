### **模型详解**

二级价格歧视，又称为**非线性定价 (Non-linear Pricing)** 或 **菜单定价 (Menu Pricing)**，是一种重要的定价策略。它的核心应用场景是：**垄断者知道市场上有不同类型的消费者（例如高需求和低需求），但无法在销售前识别出每个消费者的具体类型。**

这与另外两种价格歧视形成了对比：
*   **一级价格歧视（完美价格歧视）**：垄断者知道每个消费者的最高支付意愿，并对每个人收取这个价格。这要求垄断者拥有完美的信息。
*   **三级价格歧视**：垄断者能根据某些可观察的特征（如学生证、地区、年龄）将消费者分成不同的组，并对每个组收取不同的价格。

二级价格歧视正是解决了“信息不对称”下的定价问题。

#### **1. 模型的核心思想（对应原文的(1)-(3)点）**

*   **(1) 问题根源：识别与套利困难**
    *   当垄断者无法准确识别消费者类型（**识别问题**），或无法阻止低价购买者转售给高价购买者（**套利问题**）时，完美价格歧视就不可能实现。因为解决这两个问题的成本太高。

*   **(2) 解决方案：激励消费者自我选择**
    *   既然不能主动识别，那就设计一个“菜单 (menu)”，让消费者自己“对号入座”。这个菜单通常由不同的“价格-数量”组合（或“价格-质量”组合）构成。
    *   最常见的工具就是**数量折扣 (quantity discount)**。例如，小包装单价贵，大包装单价便宜。这样，需求量大的消费者（高需求类型）会觉得买大包装更划算，从而主动暴露了自己的身份。

*   **(3) 核心约束：高需求类型的“模仿”动机**
    *   这是整个模型最关键的约束。垄断者在设计菜单时，必须考虑一个问题：**高需求类型的消费者总是有动机去购买为低需求类型设计的套餐。**
    *   例如，一个商务旅客（高需求）完全可以去购买为学生（低需求）设计的廉价经济舱机票。如果为低需求类型设计的套餐“性价比”太高，那么高需求类型就会放弃为他们量身定制的高价套餐，导致垄断者利润受损。这个约束限制了垄断者从高需求消费者身上榨取全部消费者剩余的能力。

#### **2. 模型的推导与结论（对应原文的(4)点和结论）**

为了让高需求类型心甘情愿地选择更贵的套餐，垄断者必须让高需求套餐比低需求套餐多出来的价值，足以吸引他们。与此同时，为了从高需求类型那里赚取更多利润，垄断者会发现一个“扭曲”的策略非常有效。

*   **(4) 策略性扭曲：降低低需求套餐的吸引力**
    *   垄断者会故意降低为低需求类型设计的套餐的吸引力。最直接的方法就是**减少提供给低需求类型的数量**。
    *   这样做虽然会损失一部分从低需求类型身上赚取的利润，但好处更大：它降低了高需求类型去“模仿”的动机。因为低需求套餐变得不那么诱人了，垄断者就可以在不违反高需求类型选择动机的前提下，对高需求套餐收取更高的价格，从而在高需求类型身上榨取更多利润。

#### **3. 模型的数学表达与公式**

我们用一个标准的双类型模型来展示。

**假设:**
*   市场上有两类消费者：高需求型 (H) 和低需求型 (L)。
*   他们的人数分别为 $N_H$ 和 $N_L$。
*   消费者从消费数量 $q$ 中获得的效用为 $U = θV(q) - T$，其中 $T$ 是支付的总价。
    *   $θ$ 是消费者类型参数，$θ_H > θ_L$，表示高需求型从同等数量的商品中获得更高的边际效用。
    *   $V(q)$ 是价值函数，满足 $V'(q) > 0$ (边际效用为正) 和 $V''(q) < 0$ (边际效用递减)。
*   垄断者的生产成本为 $C(q) = cq$，即边际成本为常数 $c$。

垄断者需要设计两个套餐 $(q_L, T_L)$ 和 $(q_H, T_H)$，来最大化总利润：
$Π = N_L * (T_L - c*q_L) + N_H * (T_H - c*q_H)$

**约束条件:**
垄断者的定价必须满足两类约束：

1.  **参与约束 (Participation Constraint, PC)** 或 **个体理性约束 (Individual Rationality, IR)**：
    消费者购买套餐获得的效用不能低于不购买（效用为0）。
    *   $(PC_L)$: $θ_L * V(q_L) - T_L ≥ 0$
    *   $(PC_H)$: $θ_H * V(q_H) - T_H ≥ 0$

2.  **激励相容约束 (Incentive Compatibility Constraint, IC)** 或 **自我选择约束 (Self-Selection)**：
    每种类型的消费者都选择为自己设计的套餐，而不是为另一类型设计的套餐。
    *   $(IC_L)$: $θ_L * V(q_L) - T_L ≥ θ_L * V(q_H) - T_H$ （L型不选H套餐）
    *   $(IC_H)$: $θ_H * V(q_H) - T_H ≥ θ_H * V(q_L) - T_L$ （H型不选L套餐）

**求解与结论:**
在利润最大化时：
1.  低需求类型的**参与约束**会**紧密绑定 (binding)**，即取等号。
    $(PC_L)$: $θ_L * V(q_L) - T_L = 0$  =>  $T_L = θ_L * V(q_L)$
    *   **解释**: 垄断者会尽可能提高低需求类型的价格，直到其消费者剩余为0。这是**结论1的前半部分：榨干最低需求类型的全部消费者剩余**。

2.  高需求类型的**激励相容约束**会**紧密绑定 (binding)**，即取等号。
    $(IC_H)$: $θ_H * V(q_H) - T_H = θ_H * V(q_L) - T_L$
    *   **解释**: 这是核心约束。垄断者必须给高需求类型留下足够的“好处”（即消费者剩余），使得他们刚好不愿意去选择低需求套餐。这个“好处”被称为**信息租金 (Information Rent)**。
    *   将 $T_L$ 代入，可得 $T_H = θ_H * V(q_H) - (θ_H - θ_L)V(q_L)$。
    *   高需求类型的消费者剩余为 $CS_H = θ_H * V(q_H) - T_H = (θ_H - θ_L)V(q_L) > 0$。这印证了**结论1的后半部分：为其他所有类型留下一些消费者剩余**。

3.  将 $T_L$ 和 $T_H$ 代入利润函数，然后对 $q_L$ 和 $q_H$ 求导，可以得到最优数量的条件：
    *   对于高需求类型 $q_H$：
        $θ_H * V'(q_H) = c$
        **解释**: 高需求类型的边际效用等于边际成本。这意味着**提供给最高需求类型的数量是社会最优的**，即“**顶部无扭曲 (No Distortion at the Top)**”。

    *   对于低需求类型 $q_L$：
        $θ_L * V'(q_L) = c + (N_H / N_L) * (θ_H - θ_L) * V'(q_L)$
        **解释**: 由于公式右边第二项 $(N_H / N_L) * (θ_H - θ_L) * V'(q_L)$ 大于0，所以 $θ_L * V'(q_L) > c$。因为边际效用递减，这意味着**提供给低需求类型的数量 $q_L$ 小于社会最优水平**（社会最优水平在 $θ_L * V'(q) = c$ 处）。这就是“**向下的扭曲 (Downward Distortion)**”。

这完美地印证了**结论2：除了最高需求类型，为所有其他消费者类型提供的数量都小于社会最优数量**。

### **例题**

假设一家软件公司销售一款数据分析软件，市场上有两类用户：专业公司（H型）和学生（L型）。

*   **用户类型与效用**:
    *   专业公司 (H): $N_H = 100$ 家, 效用函数 $U_H = 10√q - T$ (即 $θ_H = 10$)
    *   学生 (L): $N_L = 120$ 人, 效用函数 $U_L = 8√q - T$ (即 $θ_L = 8$)
    *   $V(q) = √q$
*   **成本**: 软件的边际成本为 $c = 2$。

**问题**: 该软件公司应该如何设计两个版本的软件套餐（专业版 $(q_H, T_H)$ 和学生版 $(q_L, T_L)$) 来实现利润最大化？并计算此时的消费者剩余。

#### **解答步骤**

**1. 确定社会最优数量（作为基准）**
社会最优数量满足 $边际效用 = 边际成本$。
*   对H型: $θ_H * V'(q_H) = c$ => $10 * (1 / (2√q_H)) = 2$ => $5 / √q_H = 2$ => $√q_H = 2.5$ => $q_H* = 6.25$
*   对L型: $θ_L * V'(q_L) = c$ => $8 * (1 / (2√q_L)) = 2$ => $4 / √q_L = 2$ => $√q_L = 2$ => $q_L* = 4$

**2. 确定垄断者的最优数量**
根据我们的理论结论：
*   **高需求类型 (H) 的数量无扭曲**:
    $q_H = q_H* = 6.25$

*   **低需求类型 (L) 的数量被向下扭曲**:
    我们需要利用利润最大化的一阶条件来求解 $q_L$。
    利润函数 $Π = N_L * (T_L - cq_L) + N_H * (T_H - cq_H)$
    代入 $T_L = θ_L * V(q_L)$ 和 $T_H = θ_H * V(q_H) - (θ_H - θ_L)V(q_L)$:
    $Π = N_L(θ_L√q_L - cq_L) + N_H(θ_H√q_H - (θ_H - θ_L)√q_L - cq_H)$
    将利润函数对 $q_L$ 求导并令其为0:
    $∂Π/∂q_L = N_L(θ_L/(2√q_L) - c) - N_H((θ_H - θ_L)/(2√q_L)) = 0$
    $N_L*θ_L - 2c*N_L*√q_L - N_H*(θ_H - θ_L) = 0$
    $√q_L = (N_L*θ_L - N_H*(θ_H - θ_L)) / (2c*N_L)$
    代入数值:
    $√q_L = (120*8 - 100*(10 - 8)) / (2 * 2 * 120)$
    $√q_L = (960 - 200) / 480$
    $√q_L = 760 / 480 ≈ 1.583$
    $q_L ≈ 2.507$
    可以看到，$q_L ≈ 2.5$ 远小于社会最优的 $q_L* = 4$，这正是“向下的扭曲”。

**3. 确定最优价格**
*   **学生版价格 (T_L)**:
    $T_L = θ_L * V(q_L) = 8 * √q_L = 8 * 1.583 = 12.664$

*   **专业版价格 (T_H)**:
    $T_H = θ_H*V(q_H) - (θ_H - θ_L)V(q_L) = 10√6.25 - (10-8)√2.507$
    $T_H = 10 * 2.5 - 2 * 1.583 = 25 - 3.166 = 21.834$

**4. 总结最终的套餐设计**
*   **学生版**: 提供 $q_L ≈ 2.5$ 的功能/数量，定价 $T_L ≈ 12.66$。
*   **专业版**: 提供 $q_H = 6.25$ 的功能/数量，定价 $T_H ≈ 21.83$。

**5. 分析消费者剩余 (CS)**
*   **学生 (L型)**:
    $CS_L = θ_L√q_L - T_L = 8 * 1.583 - 12.664 = 12.664 - 12.664 = 0$
    学生的消费者剩余被全部榨干。

*   **专业公司 (H型)**:
    $CS_H = θ_H√q_H - T_H = 10 * 2.5 - 21.834 = 25 - 21.834 = 3.166$
    专业公司的消费者剩余为正，这部分就是为了激励他们不选择学生版而必须留给他们的**信息租金**。这个租金的大小等于 $(θ_H - θ_L)V(q_L) = (10-8) * 1.583 = 3.166$。

这个例题清晰地展示了二级价格歧视模型的所有核心结论。
