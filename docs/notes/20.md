### **模型详解：古诺模型中的等利润曲线**

#### **1. 核心定义 (Definition)**

**等利润曲线（Isoprofit Curve）** 指的是在产量组合空间 $(Q₁, Q₂)$ 中，能使某一个厂商（例如厂商1）获得**某一特定利润水平**的所有产量组合 $(Q₁, Q₂)$ 的集合。

简单来说，这条曲线上的每一个点，都代表着厂商1自己生产 $Q₁$、竞争对手厂商2生产 $Q₂$ 的一种情况，而在所有这些情况下，厂商1的利润都是**相同**的。

#### **2. 数学模型与推导 (Mathematical Model and Derivation)**

我们使用你提供的线性模型来进行分析。

*   **市场需求函数 (Market Demand):**
    市场价格 $P$ 由两个厂商的总产量 $Q₁ + Q₂$ 决定。
    $P = α - β₁Q₁ - β₂Q₂$
    为了简化，我们采纳你的设定：$β₁ = β₂ = 1$。
    于是，需求函数简化为：$P = α - (Q₁ + Q₂)$。

*   **成本函数 (Cost Function):**
    假设生产成本为零，即 $cost = 0$。这是一个常见的简化假设，便于我们聚焦于策略互动。

*   **厂商1的利润函数 (Profit Function for Firm 1):**
    利润 $π₁$ 等于总收益减去总成本。
    $π₁ (Q₁, Q₂) = P * Q₁ - cost$
    将 $P$ 和 $cost$ 代入，得到：
    $π₁ (Q₁, Q₂) = (α - Q₁ - Q₂) Q₁$
    展开后：
    $π₁ (Q₁, Q₂) = αQ₁ - Q₁² - Q₁Q₂$

*   **推导等利润曲线方程 (Deriving the Isoprofit Curve Equation):**
    根据定义，等利润曲线是利润 $π₁$ 保持恒定的所有 $(Q₁, Q₂)$ 组合。我们设这个恒定的利润值为 $π̄₁$（例如，你例子中的 $π̄₁ = 100$）。
    
    $π̄₁ = αQ₁ - Q₁² - Q₁Q₂$
    
    为了在 $(Q₁, Q₂)$ 平面（横轴为 $Q₁$，纵轴为 $Q₂$）上画出这条曲线，我们需要将 $Q₂$ 表示为 $Q₁$ 的函数。通过代数变形：
    
    $Q₁Q₂ = αQ₁ - Q₁² - π̄₁$
    
    $Q₂ = α - Q₁ - (π̄₁ / Q₁)$
    
    这就是厂商1在利润水平为 $π̄₁$ 时的**等利润曲线方程**。

#### **3. 等利润曲线的形状与特征**

这条曲线的形状不是一条直线或简单的抛物线，我们可以通过求导来分析它的斜率。

*   **对 $Q₁$ 求导:**
    $dQ₂ / dQ₁ = -1 + (π̄₁ / Q₁²)$
    这个导数告诉我们，当厂商1的产量 $Q₁$ 变化时，为了维持利润不变，厂商2的产量 $Q₂$ 需要如何相应地变化。

*   **分析斜率:**
    *   **寻找曲线的顶点 (Peak/Trough):**
        曲线的顶点（从厂商1的角度看，是其最理想的点）出现在斜率为0的地方。
        令 $dQ₂ / dQ₁ = 0$：
        $-1 + (π̄₁ / Q₁²) = 0  =>  Q₁² = π̄₁  =>  Q₁ = √π̄₁$
        以你的例子 $π̄₁ = 100$ 为例，顶点出现在 $Q₁ = √100 = 10$ 的地方。

    *   **斜率的正负:**
        *   当 $Q₁ < √π̄₁$ (例如 $Q₁ < 10$) 时，$Q₁² < π̄₁$，所以 $π̄₁ / Q₁² > 1$，导致 $dQ₂ / dQ₁ > 0$。此时曲线是**向上倾斜**的。
        *   当 $Q₁ > √π̄₁$ (例如 $Q₁ > 10$) 时，$Q₁² > π̄₁$，所以 $π̄₁ / Q₁² < 1$，导致 $dQ₂ / dQ₁ < 0$。此时曲线是**向下倾斜**的。

*   **经济学直觉:**
    等利润曲线是围绕厂商1的最优产量选择点“弯曲”的。从厂商1的角度来看，它希望 $Q₂$ 尽可能小。曲线的形状像一个向右开口的“C”形。曲线的顶点代表了：在能获得 $π̄₁$ 这个利润水平的前提下，厂商1所能容忍的**最低**的对手产量 $Q₂$。

    
    *(上图是一个示意图，横轴是Q₁, 纵轴是Q₂。曲线π₁<π₂代表厂商1的利润更低，曲线π₂代表更高的利润)*

#### **4. 利润水平与曲线的移动**

你观察到的 "isoprofit shift down with profit up" (利润越高，等利润曲线越向下移动) 是一个非常关键的特征。

*   **数学解释:**
    比较两条等利润曲线：一条代表低利润 $π̄₁$，另一条代表高利润 $π̂₁$ ($π̂₁ > π̄₁$)。
    *   低利润曲线: $Q₂ = α - Q₁ - (π̄₁ / Q₁)$
    *   高利润曲线: $Q₂ = α - Q₁ - (π̂₁ / Q₁)$
    对于任何给定的 $Q₁$，由于 $π̂₁ > π̄₁$，所以 $(π̂₁ / Q₁) > (π̄₁ / Q₁)$。因此，高利润曲线的 $Q₂$ 值会更小。这意味着代表**更高利润**的等利润曲线，在坐标系中位置更**靠下**（即更靠近 $Q₁$ 轴）。

*   **经济学直觉:**
    这非常符合逻辑。对厂商1来说，要获得更高的利润，要么是自己的产量更优，要么是市场价格更高。在自己产量 $Q₁$ 不变的情况下，只有当竞争对手厂商2的产量 $Q₂$ **减少**时，市场总供给才会下降，价格才会上升，从而使厂商1获得更高利润。因此，代表更高利润的曲线必然对应着更低的 $Q₂$ 值。

#### **5. 等利润曲线与最优反应函数 (Best Response Function) 的关系**

这是等利润曲线最重要的应用。

*   **最优反应函数 (Best Response Function / Reaction Curve):** 厂商1的最优反应函数 $R₁(Q₂)$ 给出了在给定厂商2产量 $Q₂$ 的情况下，厂商1应该选择的能使其利润最大化的产量 $Q₁$。

*   **几何关系:**
    想象厂商2选择了一个固定的产量 $Q₂*$。这在 $(Q₁, Q₂)$ 图上是一条水平线。厂商1的目标是在这条水平线上选择一个 $Q₁$ 点，使自己的利润最大化。根据我们上面的分析，利润越高的等利润曲线位置越靠下。因此，厂商1会选择能与 $Q₂*$ 这条水平线**相切**的那条**最低的**等利润曲线。
    
    相切点意味着什么？在这一点，等利润曲线的斜率为0 ($dQ₂/dQ₁ = 0$)。
    
    你提到的 "connecting the peaks of the isoprofit curves yields the firm’s best response" (连接所有等利润曲线的顶点就构成了厂商的最优反应函数) 是完全正确的。因为每个顶点都代表了在某个特定的利润水平上，厂商1在最优产量下的状态。将所有这些顶点连接起来，就描绘出了对于**任意**可能的 $Q₂$，厂商1的最优 $Q₁$ 选择。

### **例题与求解**

**题目:**
假设两个寡头厂商（厂商1和厂商2）在一个市场上进行古诺竞争。市场反需求函数为 $P = 120 - Q$，其中 $Q = Q₁ + Q₂$。两个厂商的生产成本都为零。

1.  写出厂商1的利润函数和其等利润曲线的一般方程。
2.  如果厂商1的目标利润是 $π₁ = 1600$，求出对应的等利润曲线方程，并找出该曲线的顶点坐标 $(Q₁, Q₂)$。
3.  推导出厂商1的最优反应函数 $R₁(Q₂)$。
4.  验证第2问中求出的顶点，是否位于厂商1的最优反应函数上。

**解答:**

**1. 利润函数与等利润曲线方程**

*   厂商1的利润函数：
    $π₁ (Q₁, Q₂) = P * Q₁ = (120 - Q₁ - Q₂) Q₁ = 120Q₁ - Q₁² - Q₁Q₂$

*   等利润曲线的一般方程：
    设利润为常数 $π̄₁$，则 $π̄₁ = 120Q₁ - Q₁² - Q₁Q₂$。
    整理得到 $Q₂$ 关于 $Q₁$ 的函数：
    $Q₂ = 120 - Q₁ - (π̄₁ / Q₁)$

**2. 求解 $π₁ = 1600$ 时的等利润曲线与顶点**

*   将 $π̄₁ = 1600$ 代入方程：
    $Q₂ = 120 - Q₁ - (1600 / Q₁)$

*   为了找顶点，我们对 $Q₂$ 关于 $Q₁$ 求导，并令其为0：
    $dQ₂ / dQ₁ = -1 + (1600 / Q₁²) = 0$
    $Q₁² = 1600$
    $Q₁ = 40$ （产量不能为负，故取正根）

*   当 $Q₁ = 40$ 时，我们计算对应的 $Q₂$ 值：
    $Q₂ = 120 - 40 - (1600 / 40) = 80 - 40 = 40$
    所以，当利润为1600时，等利润曲线的顶点坐标为 **(40, 40)**。

**3. 推导厂商1的最优反应函数**

*   为了求最优反应函数，我们最大化厂商1的利润函数 $π₁ = 120Q₁ - Q₁² - Q₁Q₂$。我们将 $Q₂$ 视为常数，对 $Q₁$ 求偏导，并令其为0：
    $∂π₁ / ∂Q₁ = 120 - 2Q₁ - Q₂ = 0$

*   整理得到 $Q₁$ 关于 $Q₂$ 的函数，即最优反应函数 $R₁(Q₂)$：
    $2Q₁ = 120 - Q₂$
    $Q₁ = R₁(Q₂) = 60 - 0.5Q₂$

**4. 验证顶点是否在最优反应函数上**

*   我们将顶点坐标 $(Q₁, Q₂) = (40, 40)$ 代入最优反应函数 $Q₁ = 60 - 0.5Q₂$ 的方程中进行验证。
*   将 $Q₂ = 40$ 代入方程右边：
    $60 - 0.5 * (40) = 60 - 20 = 40$
*   计算结果 $40$ 正好等于顶点的 $Q₁$ 坐标。
*   **结论：** 顶点 $(40, 40)$ 确实位于厂商1的最优反应函数上。这验证了理论：等利润曲线的顶点轨迹（集合）构成了该厂商的最优反应函数。

最后，你提到的 "cannot competition & prison’s dilemma" 是对古诺模型结果的一个经典评价。古诺均衡（即两条最优反应函数的交点）是一个纳什均衡，但它对于厂商双方来说通常不是最优的。如果它们能合谋（像一个垄断者一样生产），它们本可以获得更高的总利润。但由于每个厂商都有单方面偏离合谋协议以增加自己利润的动机，最终导致了一个对双方都更差的结果，这与**囚徒困境 (Prisoner's Dilemma)** 的逻辑是完全一致的。
